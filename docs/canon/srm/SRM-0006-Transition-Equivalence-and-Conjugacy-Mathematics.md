# SRM-0006 — Transition Equivalence and Conjugacy Mathematics

**Document ID:** SRM-0006
**Title:** Transition Equivalence and Conjugacy Mathematics
**System:** SMOF Kernel
**Domain:** State Transition Mathematics
**Status:** Canonical Draft
**Foundation Branch:** `release/foundation-v1.0`

---

## 1. Purpose

This specification defines the mathematical foundations of transition
equivalence and conjugacy within the State-Manifold Operator Framework
(SMOF).

SRM-0002 defines runtime transition.

SRM-0003 defines state transition mathematics.

SRM-0004 defines composition of transitions.

SRM-0005 defines identity and invertibility.

SRM-0006 establishes the next layer: when two transition descriptions
represent the same mathematical evolution, and when two transition
systems are related by a change of representation.

The central concepts are:

- transition equivalence;
- state equivalence;
- operator equivalence;
- observational equivalence;
- transition-system isomorphism;
- transition-system conjugacy;
- semiconjugacy;
- invariance under representation change;
- preservation of composition;
- preservation of identity;
- preservation of invertibility;
- preservation of transition traces.

---

## 2. Scope

This specification applies to deterministic transition systems whose
states and transition operators are mathematically well-defined.

Let a state space be

[
\mathcal{S}.
]

A transition operator is a map

[
P : \mathcal{D}(P) \rightarrow \mathcal{S},
]

where

[
\mathcal{D}(P) \subseteq \mathcal{S}.
]

When

[
\mathcal{D}(P)=\mathcal{S},
]

the operator is total on the state space.

The specification concerns relationships between transition operators,
state spaces, representations, and transition sequences.

---

## 3. Foundational Definitions

### 3.1 State

A state is an element

[
S \in \mathcal{S}.
]

A state represents a mathematically admissible configuration of the
system.

---

### 3.2 Transition

A transition is an ordered pair

[
S \xrightarrow{P} S',
]

satisfying

[
S'=P(S).
]

---

### 3.3 Transition operator

A transition operator is a map

[
P:\mathcal{S}_A\rightarrow\mathcal{S}_B.
]

When the source and target spaces coincide,

[
P:\mathcal{S}\rightarrow\mathcal{S},
]

the operator is an endotransition.

---

### 3.4 Transition sequence

A finite transition sequence is

[
S_0
\xrightarrow{P_0}
S_1
\xrightarrow{P_1}
S_2
\xrightarrow{P_2}
\cdots
\xrightarrow{P_{n-1}}
S_n.
]

It satisfies

[
S_{i+1}=P_i(S_i).
]

---

### 3.5 Composite transition

The composite transition associated with the sequence is

[
P_{0:n}
=
P_{n-1}\circ\cdots\circ P_1\circ P_0.
]

Therefore

[
S_n=P_{0:n}(S_0).
]

---

## 4. State Equivalence

Two states need not be literally identical to represent the same
mathematical configuration.

Define a relation

[
\sim_{\mathcal{S}}
\subseteq
\mathcal{S}\times\mathcal{S}.
]

We write

[
S\sim_{\mathcal{S}}T
]

when states `S` and `T` are equivalent under the selected state
equivalence relation.

A valid state-equivalence relation is an equivalence relation.

Thus:

### Reflexivity

For every state,

[
S\sim_{\mathcal{S}}S.
]

### Symmetry

If

[
S\sim_{\mathcal{S}}T,
]

then

[
T\sim_{\mathcal{S}}S.
]

### Transitivity

If

[
S\sim_{\mathcal{S}}T
]

and

[
T\sim_{\mathcal{S}}U,
]

then

[
S\sim_{\mathcal{S}}U.
]

---

## 5. Transition Equivalence

Two transition operators

[
P,Q
]

acting on the same state space are transition-equivalent when they
produce equivalent target states from equivalent source states.

The fundamental condition is

[
S\sim_{\mathcal{S}}T
\]

implies

[
P(S)\sim_{\mathcal{S}}Q(T).
\]

In the strict same-state representation, transition equivalence may be
defined by

[
P(S)=Q(S)
]

for every admissible state `S`.

---

## 6. Pointwise Transition Equivalence

Let

[
P,Q:\mathcal{S}\rightarrow\mathcal{S}.
]

Define pointwise equivalence by

[
P\equiv Q
]

if and only if

[
P(S)=Q(S)
]

for every

[
S\in\mathcal{S}.
]

This is the strongest basic form of transition equivalence.

It implies that every one-step transition generated by `P` is identical
to the corresponding one-step transition generated by `Q`.

---

## 7. Proposition — Pointwise Equivalence Is an Equivalence Relation

For transition operators on the same state space, the relation

[
P\equiv Q
]

defined by

[
P(S)=Q(S)
]

for every admissible state is an equivalence relation.

### Proof

Reflexivity follows because

[
P(S)=P(S).
]

Symmetry follows because

[
P(S)=Q(S)
]

implies

[
Q(S)=P(S).
]

Transitivity follows because

[
P(S)=Q(S)
]

and

[
Q(S)=R(S)
]

imply

[
P(S)=R(S).
]

Therefore

[
P\equiv Q
]

is an equivalence relation.

---

## 8. Observational Equivalence

Exact state equality may be stronger than required by an application.

Let

[
\mathcal{O}
]

be an observable space and let

[
\omega:\mathcal{S}\rightarrow\mathcal{O}
]

be an observation map.

Two states are observationally equivalent when

[
\omega(S)=\omega(T).
]

Write

[
S\sim_{\omega}T.
]

Two transition operators are observationally equivalent when

[
\omega(P(S))
=
\omega(Q(S))
]

for every admissible state.

Thus the operators may differ internally while producing identical
observations.

---

## 9. Proposition — Observational Equivalence

If

[
\omega(P(S))=\omega(Q(S))
]

for every state `S`, then the transition operators `P` and `Q` are
indistinguishable under the observable `\omega`.

### Proof

The observation produced after applying `P` is

[
\omega(P(S)).
]

The observation produced after applying `Q` is

[
\omega(Q(S)).
]

By hypothesis,

[
\omega(P(S))=\omega(Q(S)).
]

Therefore the two transitions have identical observable outcomes.

---

## 10. Transition-System Representation

A deterministic transition system may be represented by

[
\mathfrak{T}
=
(\mathcal{S},\mathcal{P}),
]

where

[
\mathcal{S}
]

is the state space and

[
\mathcal{P}
]

is a family of admissible transition operators.

If identity and composition are included, the transition family forms an
operator structure over the state space.

---

## 11. Representation Maps

Let two transition representations be

[
\mathfrak{T}_A
=
(\mathcal{S}_A,\mathcal{P}_A)
]

and

[
\mathfrak{T}_B
=
(\mathcal{S}_B,\mathcal{P}_B).
]

A representation map is a function

[
\phi:\mathcal{S}_A\rightarrow\mathcal{S}_B.
]

When `\phi` is bijective, it provides a reversible change of
representation.

---

## 12. Transport of a Transition Operator

Given a bijection

[
\phi:\mathcal{S}_A\rightarrow\mathcal{S}_B
]

and an operator

[
P:\mathcal{S}_A\rightarrow\mathcal{S}_A,
]

the transported operator on `\mathcal{S}_B` is

[
\widehat{P}
=
\phi\circ P\circ\phi^{-1}.
]

Equivalently,

[
\widehat{P}(T)
=
\phi(P(\phi^{-1}(T))).
]

This construction is the mathematical basis of conjugacy.

---

## 13. Transition Conjugacy

Two operators

[
P:\mathcal{S}_A\rightarrow\mathcal{S}_A
]

and

[
Q:\mathcal{S}_B\rightarrow\mathcal{S}_B
]

are conjugate if there exists a bijection

[
\phi:\mathcal{S}_A\rightarrow\mathcal{S}_B
]

such that

[
\phi\circ P
=
Q\circ\phi.
]

Equivalently,

[
Q
=
\phi\circ P\circ\phi^{-1}.
]

The relation may be written

[
P\sim_{\mathrm{conj}}Q.
]

---

## 14. Commuting Diagram

Conjugacy is represented by the commuting diagram

[
\begin{array}{ccc}
\mathcal{S}_A & \xrightarrow{P} & \mathcal{S}_A\\
\downarrow\phi && \downarrow\phi\\
\mathcal{S}_B & \xrightarrow{Q} & \mathcal{S}_B
\end{array}
]

The commuting condition is

[
\phi(P(S))
=
Q(\phi(S)).
]

Thus applying the transition before changing representation produces the
same represented state as changing representation before applying the
corresponding transition.

---

## 15. Fundamental Conjugacy Theorem

Let

[
\phi:\mathcal{S}_A\rightarrow\mathcal{S}_B
]

be a bijection and suppose

[
\phi\circ P=Q\circ\phi.
]

Then for every positive integer `n`,

[
\phi\circ P^n
=
Q^n\circ\phi.
]

Equivalently,

[
Q^n
=
\phi\circ P^n\circ\phi^{-1}.
]

### Proof

For `n=1`, the result is the defining conjugacy condition.

Assume

[
\phi\circ P^n=Q^n\circ\phi.
]

Then

[
\phi\circ P^{n+1}
=
(\phi\circ P^n)\circ P.
]

Using the induction hypothesis,

[
\phi\circ P^{n+1}
=
(Q^n\circ\phi)\circ P.
]

By associativity,

[
\phi\circ P^{n+1}
=
Q^n\circ(\phi\circ P).
]

Using

[
\phi\circ P=Q\circ\phi,
]

we obtain

[
\phi\circ P^{n+1}
=
Q^n\circ Q\circ\phi.
]

Therefore,

[
\phi\circ P^{n+1}
=
Q^{n+1}\circ\phi.
]

The result follows by induction.

---

## 16. Preservation of State Evolution

Let

[
S_{i+1}=P(S_i).
]

Define represented states by

[
T_i=\phi(S_i).
]

Then conjugacy gives

[
T_{i+1}
=
Q(T_i).
]

Indeed,

[
T_{i+1}
=
\phi(S_{i+1})
]

and therefore

[
T_{i+1}
=
\phi(P(S_i)).
]

Using conjugacy,

[
T_{i+1}
=
Q(\phi(S_i)).
]

Hence

[
T_{i+1}=Q(T_i).
]

Thus the entire transition trace is preserved under representation
change.

---

## 17. Trace Correspondence

Let the original trace be

[
\mathcal{E}_P
=
(S_0,S_1,\ldots,S_n).
]

The corresponding trace under `\phi` is

[
\mathcal{E}_Q
=
(\phi(S_0),\phi(S_1),\ldots,\phi(S_n)).
]

If `P` and `Q` are conjugate, then

[
S_{i+1}=P(S_i)
]

if and only if

[
\phi(S_{i+1})=Q(\phi(S_i)).
]

Therefore the representation map sends valid `P`-traces to valid
`Q`-traces.

---

## 18. Composition Preservation

Suppose

[
P,Q
]

are composable operators and `\phi` is a conjugacy map.

The transported operators satisfy

[
\widehat{P\circ Q}
=
\widehat{P}\circ\widehat{Q}.
]

### Proof

By definition,

[
\widehat{P\circ Q}
=
\phi\circ(P\circ Q)\circ\phi^{-1}.
]

By associativity,

[
\widehat{P\circ Q}
=
\phi\circ P\circ Q\circ\phi^{-1}.
]

Insert the identity

[
I=\phi^{-1}\circ\phi
]

between `P` and `Q`:

[
\widehat{P\circ Q}
=
(\phi\circ P\circ\phi^{-1})
\circ
(\phi\circ Q\circ\phi^{-1}).
]

Therefore,

[
\widehat{P\circ Q}
=
\widehat{P}\circ\widehat{Q}.
]

---

## 19. Identity Preservation

Let

[
I_A
]

be the identity on `\mathcal{S}_A`.

Under conjugacy,

[
\widehat{I_A}
=
\phi\circ I_A\circ\phi^{-1}.
]

Since

[
I_A(\phi^{-1}(T))
=
\phi^{-1}(T),
]

we obtain

[
\widehat{I_A}(T)
=
\phi(\phi^{-1}(T)).
]

Therefore,

[
\widehat{I_A}(T)=T.
]

Hence

[
\widehat{I_A}=I_B.
]

A change of representation preserves the identity transition.

---

## 20. Invertibility Preservation

Suppose `P` is invertible.

Then

[
P^{-1}\circ P=I_A
]

and

[
P\circ P^{-1}=I_A.
]

Define

[
Q
=
\phi\circ P\circ\phi^{-1}.
]

Then

[
Q^{-1}
=
\phi\circ P^{-1}\circ\phi^{-1}.
]

Indeed,

[
Q^{-1}\circ Q
=
(\phi\circ P^{-1}\circ\phi^{-1})
\circ
(\phi\circ P\circ\phi^{-1}).
]

Therefore,

[
Q^{-1}\circ Q
=
\phi\circ(P^{-1}\circ P)\circ\phi^{-1}.
]

Hence,

[
Q^{-1}\circ Q
=
\phi\circ I_A\circ\phi^{-1}.
]

Using identity preservation,

[
Q^{-1}\circ Q=I_B.
]

Similarly,

[
Q\circ Q^{-1}=I_B.
]

Thus invertibility is invariant under conjugacy.

---

## 21. Inverse Transition Correspondence

If

[
T=\phi(S),
]

then

[
Q^{-1}(T)
=
\phi(P^{-1}(S)).
]

Thus reversing a transition before representation change is equivalent to
representation change followed by the represented inverse transition.

This gives

[
\phi\circ P^{-1}
=
Q^{-1}\circ\phi.
]

---

## 22. Fixed Points

A state `S` is a fixed point of `P` if

[
P(S)=S.
]

Suppose `P` and `Q` are conjugate through `\phi`.

If

[
P(S)=S,
]

then

[
Q(\phi(S))
=
\phi(P(S)).
]

Therefore,

[
Q(\phi(S))
=
\phi(S).
]

Hence `\phi(S)` is a fixed point of `Q`.

Thus conjugacy establishes a bijection between fixed-point sets:

[
\operatorname{Fix}(Q)
=
\phi(\operatorname{Fix}(P)).
]

---

## 23. Periodic States

A state `S` has period `k` under `P` if

[
P^k(S)=S
]

for some positive integer `k`.

Under conjugacy,

[
Q^k(\phi(S))
=
\phi(P^k(S)).
]

Therefore,

[
Q^k(\phi(S))
=
\phi(S).
]

Hence periodicity is preserved.

If `k` is the least positive period of `S`, then the least positive period
of `\phi(S)` under `Q` is also `k`.

---

## 24. Orbit Correspondence

The forward orbit of `S` under `P` is

[
\mathcal{O}_P(S)
=
\{P^n(S):n\geq0\}.
]

The corresponding orbit under `Q` is

[
\mathcal{O}_Q(\phi(S))
=
\{Q^n(\phi(S)):n\geq0\}.
]

By conjugacy,

[
Q^n(\phi(S))
=
\phi(P^n(S)).
]

Therefore,

[
\mathcal{O}_Q(\phi(S))
=
\phi(\mathcal{O}_P(S)).
]

Conjugacy preserves orbit structure.

---

## 25. Transition Equivalence of Composites

Suppose

[
P_i\equiv Q_i
]

for each member of a finite sequence.

Then

[
P_{n-1}\circ\cdots\circ P_0
\equiv
Q_{n-1}\circ\cdots\circ Q_0.
]

### Proof

For every state `S`,

[
P_0(S)=Q_0(S).
]

Applying the next equivalent operators gives

[
P_1(P_0(S))
=
Q_1(Q_0(S)).
]

Repeating this argument through the sequence yields

[
P_{n-1}\circ\cdots\circ P_0(S)
=
Q_{n-1}\circ\cdots\circ Q_0(S).
]

Therefore the composite operators are pointwise equivalent.

---

## 26. Equivalence of Transition Sequences

Two transition sequences

[
\mathcal{T}_P
=
(S_0,P_0,S_1,\ldots,P_{n-1},S_n)
]

and

[
\mathcal{T}_Q
=
(T_0,Q_0,T_1,\ldots,Q_{n-1},T_n)
]

are equivalent under a bijection `\phi` when

[
T_i=\phi(S_i)
]

for every state and

[
\phi\circ P_i
=
Q_i\circ\phi
]

for every transition operator.

This condition establishes correspondence at every transition step.

---

## 27. Transition-Sequence Equivalence Theorem

If every operator pair satisfies

[
\phi\circ P_i
=
Q_i\circ\phi,
]

then

[
T_i=\phi(S_i)
]

for every corresponding state.

### Proof

For the initial state,

[
T_0=\phi(S_0).
]

Assume

[
T_i=\phi(S_i).
]

Then

[
T_{i+1}
=
Q_i(T_i).
]

Substitute the induction hypothesis:

[
T_{i+1}
=
Q_i(\phi(S_i)).
]

By conjugacy,

[
T_{i+1}
=
\phi(P_i(S_i)).
]

Since

[
S_{i+1}=P_i(S_i),
]

we obtain

[
T_{i+1}
=
\phi(S_{i+1}).
]

Therefore the result holds for every transition in the sequence.

---

## 28. Semiconjugacy

A map

[
\phi:\mathcal{S}_A\rightarrow\mathcal{S}_B
]

is a semiconjugacy from `P` to `Q` if

[
\phi\circ P
=
Q\circ\phi.
]

Unlike conjugacy, `\phi` need not be bijective.

Therefore:

- conjugacy requires a bijective representation map;
- semiconjugacy requires only a compatible map.

Semiconjugacy can identify multiple states of one system with a single
state of another system.

---

## 29. Quotient Transition Systems

Suppose an equivalence relation

[
\sim
]

partitions the state space.

The quotient state space is

[
\mathcal{S}/\sim.
]

A transition operator descends to the quotient when

[
S\sim T
\]

implies

[
P(S)\sim P(T).
]

In this case define

[
\overline{P}([S])
=
[P(S)].
]

This definition is well-defined because equivalent representatives have
equivalent images.

---

## 30. Quotient Compatibility Theorem

If

[
S\sim T
]

implies

[
P(S)\sim P(T),
]

then the quotient transition

[
\overline{P}:\mathcal{S}/\sim\rightarrow\mathcal{S}/\sim
]

is well-defined.

### Proof

Suppose

[
[S]=[T].
]

Then

[
S\sim T.
]

By compatibility,

[
P(S)\sim P(T).
]

Therefore,

[
[P(S)]=[P(T)].
]

Hence the value of

[
\overline{P}([S])
=
[P(S)]
]

does not depend on the chosen representative.

---

## 31. Equivalence Classes of Operators

Let `\mathfrak{P}` be a family of transition operators.

Define

[
P\approx Q
]

when `P` and `Q` are conjugate.

The conjugacy class of `P` is

[
[P]_{\mathrm{conj}}
=
\{Q:Q\sim_{\mathrm{conj}}P\}.
]

All operators in the same conjugacy class represent the same transition
dynamics up to a bijective change of state representation.

---

## 32. Conjugacy Is an Equivalence Relation

Conjugacy of deterministic transition systems is an equivalence relation
when the conjugating maps are bijections.

### Reflexivity

Use the identity map:

[
I\circ P=P\circ I.
]

Therefore,

[
P\sim_{\mathrm{conj}}P.
]

### Symmetry

If

[
\phi\circ P=Q\circ\phi,
]

then

[
P
=
\phi^{-1}\circ Q\circ\phi.
]

Therefore,

[
Q\sim_{\mathrm{conj}}P.
]

### Transitivity

Suppose

[
\phi\circ P=Q\circ\phi
]

and

[
\psi\circ Q=R\circ\psi.
]

Then

[
(\psi\circ\phi)\circ P
=
R\circ(\psi\circ\phi).
]

Since the composition of bijections is bijective,

[
P\sim_{\mathrm{conj}}R.
]

Thus conjugacy is an equivalence relation.

---

## 33. Preservation of Composition Algebra

Conjugacy is compatible with the composition structure defined by
SRM-0004.

If

[
\widehat{P}
=
\phi P\phi^{-1}
]

and

[
\widehat{Q}
=
\phi Q\phi^{-1},
]

then

[
\widehat{P}\circ\widehat{Q}
=
\phi(P\circ Q)\phi^{-1}.
]

Thus the representation transformation is an algebra-preserving map.

---

## 34. Preservation of Identity and Inverse Algebra

The identity satisfies

[
\phi I\phi^{-1}=I.
]

The inverse satisfies

[
\phi P^{-1}\phi^{-1}
=
(\phi P\phi^{-1})^{-1}.
]

Therefore the structural laws introduced by SRM-0005 are preserved under
conjugacy.

---

## 35. Transition Invariants

A transition invariant is a property that remains unchanged under the
selected equivalence relation.

Under conjugacy, the following are preserved:

- fixed points;
- periodicity;
- orbit structure;
- orbit cardinality;
- composition depth;
- invertibility;
- existence of inverse transitions;
- transition trace length;
- identity structure;
- algebraic composition relationships.

These invariants allow a system to be studied independently of a chosen
state representation.

---

## 36. Representation Invariance Principle

Let

[
\mathfrak{T}_A
]

and

[
\mathfrak{T}_B
]

be conjugate transition systems.

Then any property defined solely in terms of the transition structure and
preserved by conjugacy has the same truth value in both systems.

Symbolically, if `I` is a conjugacy invariant,

[
I(P)=I(Q).
]

This is the mathematical basis for representation-independent runtime
reasoning.

---

## 37. Runtime Interpretation

Suppose a runtime stores states in representation `R_A` and another
runtime stores mathematically corresponding states in representation
`R_B`.

Let

[
\phi:R_A\rightarrow R_B
]

be the representation conversion.

If

[
\phi\circ P_A
=
P_B\circ\phi,
]

then the two runtimes implement the same transition semantics up to
representation.

The runtime therefore satisfies the semantic correspondence condition:

[
\operatorname{decode}_B(R_B')
=
\phi(
\operatorname{decode}_A(R_A')
).
]

---

## 38. Runtime Correctness Under Conjugacy

Let encoded runtime states be

[
R_i^A
]

and

[
R_i^B.
]

Suppose

[
S_i^A=\operatorname{decode}_A(R_i^A)
]

and

[
S_i^B=\operatorname{decode}_B(R_i^B).
]

If

[
S_i^B=\phi(S_i^A)
]

and

[
\phi\circ P_A=P_B\circ\phi,
]

then correct runtime execution requires

[
S_{i+1}^A=P_A(S_i^A)
]

and

[
S_{i+1}^B=P_B(S_i^B).
]

Consequently,

[
S_{i+1}^B
=
\phi(S_{i+1}^A).
]

---

## 39. Semantic Commutativity

A runtime representation is semantically correct when the following
relationship commutes:

[
\operatorname{decode}_B
\circ
\operatorname{execute}_B
=
\phi
\circ
\operatorname{decode}_A
\circ
\operatorname{execute}_A.
]

This expresses preservation of mathematical meaning through different
runtime representations.

---

## 40. Conjugacy of Composite Runtime Transitions

For a sequence

[
P_{0:n}
=
P_{n-1}\circ\cdots\circ P_0,
]

the corresponding representation is

[
Q_{0:n}
=
Q_{n-1}\circ\cdots\circ Q_0.
]

If every transition satisfies

[
\phi\circ P_i=Q_i\circ\phi,
]

then

[
\phi\circ P_{0:n}
=
Q_{0:n}\circ\phi.
]

Therefore entire transition programs may be transported between
equivalent representations.

---

## 41. Normal Form

A transition representation is in a conjugacy-normalized form when all
representation-dependent structure has been factored through a chosen
bijection

[
\phi.
]

The normalized operator is

[
P_{\mathrm{norm}}
=
\phi\circ P\circ\phi^{-1}.
]

Different implementations that produce the same normalized operator are
conjugacy-equivalent.

---

## 42. Canonical Transition Identity

The canonical identity transition is

[
I_{\mathcal{S}}(S)=S.
]

Under any bijection `\phi`,

[
\phi\circ I_{\mathcal{S}}\circ\phi^{-1}
=
I_{\mathcal{S}'}.
]

Therefore identity has representation-independent semantics.

---

## 43. Canonical Inverse

If

[
P^{-1}
]

exists, then its represented form is

[
\widehat{P^{-1}}
=
\phi\circ P^{-1}\circ\phi^{-1}.
]

The represented inverse is exactly the inverse of the represented
transition:

[
\widehat{P^{-1}}
=
\widehat{P}^{-1}.
]

## 44. Main Theorem

### Transition Equivalence and Conjugacy Theorem

Let

[
P:\mathcal{S}_A\rightarrow\mathcal{S}_A
]

and

[
Q:\mathcal{S}_B\rightarrow\mathcal{S}_B
]

be deterministic transition operators.

If there exists a bijection

[
\phi:\mathcal{S}_A\rightarrow\mathcal{S}_B
]

such that

[
\phi\circ P
=
Q\circ\phi,
]

then:

1. one-step transitions correspond;
2. finite transition sequences correspond;
3. composite transitions correspond;
4. identity transitions correspond;
5. inverse transitions correspond when they exist;
6. fixed points correspond;
7. periodic states correspond;
8. orbits correspond;
9. transition-system structure is preserved;
10. all conjugacy-invariant properties are preserved.

Therefore `P` and `Q` represent the same deterministic transition
dynamics up to the bijective change of state representation `\phi`.

---

## 45. Proof of the Main Theorem

The one-step correspondence follows directly from

[
\phi\circ P=Q\circ\phi.
]

Repeated application gives

[
\phi\circ P^n=Q^n\circ\phi.
]

Therefore finite transition sequences correspond.

Composition preservation follows from

[
\phi(P\circ Q)\phi^{-1}
=
(\phi P\phi^{-1})
\circ
(\phi Q\phi^{-1}).
]

Identity preservation follows from

[
\phi I\phi^{-1}=I.
]

If `P` is invertible, then

[
(\phi P\phi^{-1})^{-1}
=
\phi P^{-1}\phi^{-1}.
]

Fixed points and periodic states follow from the preservation of powers of
the operator.

Orbit correspondence follows from

[
Q^n(\phi(S))
=
\phi(P^n(S)).
]

Thus every listed structural property is preserved.

## 51. Minimal Verification Algorithm

Given `P`, `Q`, and `\phi`:

1. verify the domains;
2. verify the codomains;
3. verify that `\phi` is bijective;
4. compute `\phi(P(S))`;
5. compute `Q(\phi(S))`;
6. compare the results;
7. repeat for all required states or prove equality symbolically;
8. verify composition;
9. verify identity;
10. verify inverse if applicable;
11. certify the conjugacy relation.

The core equality is:

[
\phi(P(S))
=
Q(\phi(S)).
]
