# SRM-0007 — Transition Reachability and Orbit Mathematics

**Document ID:** SRM-0007
**Title:** Transition Reachability and Orbit Mathematics
**System:** SMOF Kernel
**Domain:** State Transition Mathematics
**Status:** Canonical Draft
**Predecessors:** SRM-0002, SRM-0003, SRM-0004, SRM-0005, SRM-0006

---

# 1. Purpose

SRM-0007 defines the mathematical foundations of reachability and orbit structure for the SMOF Runtime.

The specification extends the transition algebra established by the preceding SRM artifacts.

SRM-0002 establishes runtime transition.

SRM-0003 establishes state transition mathematics.

SRM-0004 establishes transition composition.

SRM-0005 establishes identity and invertibility.

SRM-0006 establishes transition equivalence and conjugacy.

SRM-0007 establishes the mathematics required to determine which states can be reached, how states evolve under repeated transitions, and how transition orbits are structured.

The principal objects introduced are:

- reachable states;
- reachable sets;
- transition paths;
- forward orbits;
- backward orbits;
- full orbits;
- invariant sets;
- positively invariant sets;
- negatively invariant sets;
- periodic states;
- periodic orbits;
- fixed points;
- recurrent states;
- orbit equivalence classes.

---

# 2. Scope

SRM-0007 applies to deterministic transition systems represented by

\[
P : S \to S.
\]

The state space is denoted by \(S\).

A transition operator is denoted by \(P\).

Repeated application of the operator generates state evolution.

The specification addresses both invertible and non-invertible transition operators.

For invertible operators, forward and backward evolution are both defined.

For non-invertible operators, only the mathematically valid directions of evolution are considered.

---

# 3. Foundational State-Transition Model

Let

\[
S
\]

be a state space.

Let

\[
P : S \to S
\]

be a transition operator.

For an initial state

\[
S_0 \in S,
\]

define

\[
S_1 = P(S_0).
\]

A second transition gives

\[
S_2 = P(S_1).
\]

Therefore,

\[
S_2 = P(P(S_0)).
\]

By composition,

\[
S_2 = P^2(S_0).
\]

More generally,

\[
S_n = P^n(S_0).
\]

This establishes repeated transition as the fundamental mechanism underlying orbit generation.

---

# 4. Iteration of a Transition Operator

Define the zeroth iterate by

\[
P^0 = I_S,
\]

where \(I_S\) is the identity operator on \(S\).

For every positive integer \(n\),

\[
P^n = \underbrace{P \circ P \circ \cdots \circ P}_{n\text{ times}}.
\]

Therefore,

\[
P^{n+1} = P \circ P^n.
\]

By associativity,

\[
P^{m+n} = P^m \circ P^n.
\]

For a state \(S\),

\[
P^{m+n}(S) = P^m(P^n(S)).
\]

This provides the algebraic foundation for discrete transition evolution.

---

# 5. Transition Path

A transition path of length \(n\) beginning at \(S_0\) is the sequence

\[
(S_0,S_1,\ldots,S_n)
\]

such that

\[
S_{i+1} = P(S_i)
\]

for every valid index \(i\).

Therefore,

\[
S_i = P^i(S_0).
\]

The path records the ordered states generated by repeated application of the transition operator.

---

# 6. Reachability

Let

\[
x,y \in S.
\]

The state \(y\) is reachable from \(x\) under \(P\) if there exists an integer

\[
n \geq 0
\]

such that

\[
y = P^n(x).
\]

We write

\[
x \rightsquigarrow_P y.
\]

Therefore,

\[
x \rightsquigarrow_P y
\iff
\exists n \in \mathbb{N}_0 :
y = P^n(x).
\]

Reachability is therefore defined through finite transition iteration.

---

# 7. Zero-Step Reachability

Because

\[
P^0 = I_S,
\]

every state reaches itself in zero transitions.

For every

\[
x \in S,
\]

we have

\[
x \rightsquigarrow_P x.
\]

Thus reachability is reflexive.

---

# 8. Reachability Transitivity

Suppose

\[
x \rightsquigarrow_P y
\]

and

\[
y \rightsquigarrow_P z.
\]

Then there exist integers

\[
m,n \geq 0
\]

such that

\[
y = P^m(x)
\]

and

\[
z = P^n(y).
\]

Substitution gives

\[
z = P^n(P^m(x)).
\]

Therefore,

\[
z = P^{n+m}(x).
\]

Hence,

\[
x \rightsquigarrow_P z.
\]

Reachability is therefore transitive.

---

# 9. Reachability Relation

Define the reachability relation

\[
\mathcal{R}_P
\]

by

\[
\mathcal{R}_P
=
\{(x,y)\in S\times S : x\rightsquigarrow_P y\}.
\]

The relation contains every ordered pair for which the second state can be obtained from the first through finite iteration.

Because reachability is reflexive and transitive,

\[
\mathcal{R}_P
\]

is a preorder.

---

# 10. Reachable Set

For a state

\[
x \in S,
\]

define the forward reachable set

\[
\operatorname{Reach}_P(x)
\]

by

\[
\operatorname{Reach}_P(x)
=
\{P^n(x):n\in\mathbb{N}_0\}.
\]

Therefore,

\[
x \in \operatorname{Reach}_P(x).
\]

The reachable set contains the initial state and every state obtained through finite forward iteration.

---

# 11. Reachable Set Recursion

The reachable set satisfies

\[
\operatorname{Reach}_P(x)
=
\{x\}
\cup
P(\operatorname{Reach}_P(x)).
\]

Equivalently,

\[
\operatorname{Reach}_P(x)
=
\{x,P(x),P^2(x),P^3(x),\ldots\}.
\]

This gives the operational construction of the reachable set.

---

# 12. Reachability of a Set

For a subset

\[
A \subseteq S,
\]

define

\[
\operatorname{Reach}_P(A)
=
\bigcup_{x\in A}\operatorname{Reach}_P(x).
\]

Therefore,

\[
\operatorname{Reach}_P(A)
=
\bigcup_{n\geq0}P^n(A).
\]

This construction extends reachability from individual states to collections of states.

---

# 13. Forward Orbit

The forward orbit of \(x\) under \(P\) is

\[
\mathcal{O}_P^+(x)
=
\{P^n(x):n\in\mathbb{N}_0\}.
\]

Thus,

\[
\mathcal{O}_P^+(x)
=
\operatorname{Reach}_P(x).
\]

The terms forward orbit and reachable set coincide for deterministic forward iteration.

---

# 14. Orbit Sequence

The forward orbit sequence is

\[
\mathcal{E}_P(x)
=
(x,P(x),P^2(x),P^3(x),\ldots).
\]

The orbit set removes ordering and retains the states:

\[
\mathcal{O}_P^+(x)
=
\{x,P(x),P^2(x),\ldots\}.
\]

The orbit sequence is therefore an ordered representation of the orbit set.

---

# 15. Orbit Map

Define the orbit map

\[
\omega_x:\mathbb{N}_0\to S
\]

by

\[
\omega_x(n)=P^n(x).
\]

Then

\[
\omega_x(0)=x
\]

and

\[
\omega_x(n+1)=P(\omega_x(n)).
\]

The orbit is therefore generated by a map from the non-negative integers into the state space.

---

# 16. Orbit as a Dynamical Object

The orbit of \(x\) is not merely a list of states.

It is the state subset generated by repeated application of \(P\).

Thus,

\[
\mathcal{O}_P^+(x)
=
\operatorname{Im}(\omega_x).
\]

The orbit therefore represents the complete forward transition history of \(x\) under the operator.

---

# 17. Orbit Closure Under the Operator

For every

\[
y\in\mathcal{O}_P^+(x),
\]

we have

\[
P(y)\in\mathcal{O}_P^+(x).
\]

Proof:

Let

\[
y=P^n(x).
\]

Then

\[
P(y)=P(P^n(x)).
\]

Therefore,

\[
P(y)=P^{n+1}(x).
\]

Hence,

\[
P(y)\in\mathcal{O}_P^+(x).
\]

The forward orbit is therefore forward invariant.

---

# 18. Forward Invariance

A subset

\[
A\subseteq S
\]

is positively invariant under \(P\) if

\[
P(A)\subseteq A.
\]

Equivalently,

\[
x\in A
\implies
P(x)\in A.
\]

Every forward orbit is positively invariant.

---

# 19. Minimal Positively Invariant Set

The forward orbit of \(x\) is the smallest positively invariant subset containing \(x\).

Let

\[
A\subseteq S
\]

satisfy

\[
x\in A
\]

and

\[
P(A)\subseteq A.
\]

Then

\[
\mathcal{O}_P^+(x)\subseteq A.
\]

Therefore,

\[
\mathcal{O}_P^+(x)
\]

is the minimal positively invariant set containing \(x\).

---

# 20. Invariant Set

A subset

\[
A\subseteq S
\]

is invariant under \(P\) if

\[
P(A)=A.
\]

This requires both

\[
P(A)\subseteq A
\]

and

\[
A\subseteq P(A).
\]

For an invertible transition operator, this is equivalent to

\[
P(A)=A
\iff
P^{-1}(A)=A.
\]

---

# 21. Negative Invariance

A subset

\[
A\subseteq S
\]

is negatively invariant if

\[
A\subseteq P(A).
\]

Negative invariance concerns whether every state in \(A\) has a predecessor within \(A\).

For non-invertible operators, negative invariance must not be confused with the existence of a globally defined inverse.

---

# 22. Preimage

For a subset

\[
A\subseteq S,
\]

define the preimage

\[
P^{-1}(A)
=
\{x\in S:P(x)\in A\}.
\]

This notation denotes a set-theoretic preimage.

It does not require \(P\) itself to be invertible.

This distinction is fundamental for non-invertible transition systems.

---

# 23. One-Step Predecessor Set

For a state

\[
y\in S,
\]

define

\[
\operatorname{Pred}_P(y)
=
\{x\in S:P(x)=y\}.
\]

Thus,

\[
\operatorname{Pred}_P(y)
=
P^{-1}(\{y\}).
\]

A state may have zero, one, or many predecessors.

---

# 24. Backward Reachability

The backward reachable set of \(y\) is

\[
\operatorname{BackReach}_P(y)
=
\bigcup_{n\geq0}P^{-n}(\{y\}).
\]

Equivalently,

\[
\operatorname{BackReach}_P(y)
=
\{x\in S:\exists n\geq0,\ P^n(x)=y\}.
\]

This set contains all states that can reach \(y\).

---

# 25. Forward and Backward Reachability

Forward reachability asks:

\[
x \rightsquigarrow_P y?
\]

Backward reachability asks:

\[
y \in \operatorname{Reach}_P(x)?
\]

Equivalently,

\[
x \in \operatorname{BackReach}_P(y).
\]

These are two representations of the same transition relation.

---

# 26. Invertible Transition Operators

Suppose

\[
P:S\to S
\]

is invertible.

Then there exists

\[
P^{-1}:S\to S
\]

such that

\[
P^{-1}\circ P=I_S
\]

and

\[
P\circ P^{-1}=I_S.
\]

In this case, negative iterates are defined by

\[
P^{-n}=(P^{-1})^n.
\]

---

# 27. Full Orbit

For an invertible operator, define the full orbit of \(x\) by

\[
\mathcal{O}_P(x)
=
\{P^n(x):n\in\mathbb{Z}\}.
\]

This includes both forward and backward states.

Therefore,

\[
\mathcal{O}_P(x)
=
\mathcal{O}_P^+(x)
\cup
\mathcal{O}_P^-(x).
\]

where

\[
\mathcal{O}_P^-(x)
=
\{P^{-n}(x):n\in\mathbb{N}\}.
\]

---

# 28. Full Orbit Invariance

For an invertible operator,

\[
P(\mathcal{O}_P(x))
=
\mathcal{O}_P(x).
\]

Proof follows because

\[
P(P^n(x))
=
P^{n+1}(x)
\]

for every

\[
n\in\mathbb{Z}.
\]

Since \(n+1\) also ranges over all integers, the orbit remains unchanged.

---

# 29. Orbit Equivalence

For an invertible transition operator, define

\[
x\sim_P y
\]

if

\[
y=P^n(x)
\]

for some

\[
n\in\mathbb{Z}.
\]

Equivalently,

\[
x\sim_P y
\iff
y\in\mathcal{O}_P(x).
\]

---

# 30. Orbit Equivalence Is Reflexive

For every

\[
x\in S,
\]

we have

\[
x=P^0(x).
\]

Therefore,

\[
x\sim_P x.
\]

---

# 31. Orbit Equivalence Is Symmetric

Suppose

\[
x\sim_P y.
\]

Then

\[
y=P^n(x)
\]

for some integer \(n\).

Applying \(P^{-n}\),

\[
x=P^{-n}(y).
\]

Therefore,

\[
y\sim_P x.
\]

---

# 32. Orbit Equivalence Is Transitive

Suppose

\[
x\sim_P y
\]

and

\[
y\sim_P z.
\]

Then

\[
y=P^m(x)
\]

and

\[
z=P^n(y).
\]

Therefore,

\[
z=P^n(P^m(x)).
\]

Hence,

\[
z=P^{n+m}(x).
\]

Therefore,

\[
x\sim_P z.
\]

Thus orbit equivalence is an equivalence relation.

---

# 33. Orbit Equivalence Classes

The equivalence class of \(x\) is

\[
[x]_P
=
\{y\in S:x\sim_P y\}.
\]

For an invertible operator,

\[
[x]_P=\mathcal{O}_P(x).
\]

Thus full orbits are exactly the equivalence classes generated by orbit equivalence.

---

# 34. Fixed Point

A state

\[
x\in S
\]

is a fixed point of \(P\) if

\[
P(x)=x.
\]

The fixed-point set is

\[
\operatorname{Fix}(P)
=
\{x\in S:P(x)=x\}.
\]

For a fixed point,

\[
P^n(x)=x
\]

for every

\[
n\geq0.
\]

Therefore,

\[
\mathcal{O}_P^+(x)=\{x\}.
\]

---

# 35. Periodic State

A state

\[
x\in S
\]

is periodic if there exists an integer

\[
k>0
\]

such that

\[
P^k(x)=x.
\]

The smallest positive such integer is the period of \(x\).

Denote it by

\[
\operatorname{per}_P(x).
\]

If

\[
\operatorname{per}_P(x)=k,
\]

then

\[
P^k(x)=x
\]

and

\[
P^j(x)\neq x
\]

for

\[
0<j<k.
\]

---

# 36. Fixed Points as Period-One Orbits

Every fixed point is periodic with period one.

If

\[
P(x)=x,
\]

then

\[
P^1(x)=x.
\]

Therefore,

\[
\operatorname{per}_P(x)=1.
\]

Hence,

\[
\operatorname{Fix}(P)
\subseteq
\operatorname{Per}(P).
\]

---

# 37. Periodic Orbit

If \(x\) has period \(k\), its orbit is

\[
\mathcal{O}_P(x)
=
\{x,P(x),\ldots,P^{k-1}(x)\}.
\]

The orbit contains at most \(k\) states.

For a state with minimal period \(k\), the orbit contains exactly \(k\) distinct states.

---

# 38. Periodic Orbit Closure

For a periodic state,

\[
P^k(x)=x.
\]

Therefore,

\[
P^{n+k}(x)=P^n(x)
\]

for every

\[
n\geq0.
\]

Thus the infinite orbit sequence is periodic.

---

# 39. Eventual Periodicity

A state is eventually periodic if there exist integers

\[
m\geq0
\]

and

\[
k>0
\]

such that

\[
P^{m+k}(x)=P^m(x).
\]

The state may first enter a transient region and subsequently enter a periodic orbit.

The integer \(m\) is an entry time and \(k\) is a period of the eventual cycle.

---

# 40. Transient Segment

For an eventually periodic state, the transient segment is

\[
x,P(x),\ldots,P^{m-1}(x).
\]

The periodic component begins at

\[
P^m(x).
\]

Therefore the orbit has the structural form

\[
\text{transient}\to\text{cycle}.
\]

---

# 41. Reachability of Periodic States

If

\[
y=P^m(x)
\]

and \(y\) is periodic with period \(k\), then

\[
P^{m+k}(x)=P^m(x).
\]

Therefore \(x\) is eventually periodic.

This establishes that reachability of a periodic state implies eventual periodicity of the originating state.

---

# 42. Orbit Intersection

Suppose

\[
\mathcal{O}_P^+(x)
\cap
\mathcal{O}_P^+(y)
\neq\varnothing.
\]

Then there exist integers \(m,n\geq0\) such that

\[
P^m(x)=P^n(y).
\]

The two forward trajectories therefore enter a common future state.

For deterministic transitions, their future evolution from that common state is identical.

---

# 43. Common-Future Theorem

If

\[
P^m(x)=P^n(y),
\]

then for every

\[
r\geq0,
\]

we have

\[
P^{m+r}(x)=P^{n+r}(y).
\]

Proof:

\[
P^{m+r}(x)
=
P^r(P^m(x)).
\]

Since

\[
P^m(x)=P^n(y),
\]

we obtain

\[
P^r(P^m(x))
=
P^r(P^n(y)).
\]

Therefore,

\[
P^{m+r}(x)=P^{n+r}(y).
\]

---

# 44. Deterministic Orbit Merging

The common-future theorem implies that deterministic trajectories can merge.

If

\[
P(x)=P(y),
\]

then

\[
P^n(x)=P^n(y)
\]

for every

\[
n\geq1.
\]

Thus non-invertible operators may identify distinct histories.

---

# 45. Invertibility Prevents Forward Merging

Suppose \(P\) is invertible.

If

\[
P^m(x)=P^m(y),
\]

then applying \(P^{-m}\) gives

\[
x=y.
\]

Therefore, distinct states cannot merge under an invertible transition operator.

This distinguishes invertible dynamics from non-invertible dynamics.

---

# 46. Orbit Structure Under Invertibility

For an invertible operator, every orbit has a complete two-sided history.

Thus

\[
\mathcal{O}_P(x)
=
\{P^n(x):n\in\mathbb{Z}\}.
\]

The operator restricts to a bijection on each orbit.

Therefore,

\[
P|_{\mathcal{O}_P(x)}
:
\mathcal{O}_P(x)\to\mathcal{O}_P(x)
\]

is bijective.

---

# 47. Orbit Partition

For an invertible operator, orbit equivalence partitions the state space.

Therefore,

\[
S
=
\bigsqcup_{[x]_P\in S/{\sim_P}}
[x]_P.
\]

Distinct orbit classes are disjoint.

If two orbit classes intersect, they are equal.

---

# 48. Reachability Classes

For general deterministic operators, mutual reachability is defined by

\[
x\approx_P y
\]

if

\[
x\rightsquigarrow_P y
\]

and

\[
y\rightsquigarrow_P x.
\]

This relation is reflexive, symmetric, and transitive.

Therefore it is an equivalence relation.

---

# 49. Mutual Reachability

If

\[
x\approx_P y,
\]

then there exist integers

\[
m,n\geq0
\]

such that

\[
y=P^m(x)
\]

and

\[
x=P^n(y).
\]

Consequently,

\[
x=P^{n+m}(x).
\]

Thus every mutually reachable state lies on a periodic orbit.

---

# 50. Strongly Connected Transition Classes

Define

\[
[x]_{\approx_P}
=
\{y\in S:x\approx_P y\}.
\]

These classes are the strongly connected components of the deterministic transition relation.

A singleton fixed point is a strongly connected class.

A nontrivial periodic orbit forms a strongly connected class.

---

# 51. Reachability Partial Order on Classes

Mutual reachability collapses states into equivalence classes.

On the resulting quotient structure, define

\[
[x]_{\approx_P}
\preceq
[y]_{\approx_P}
\]

if

\[
x\rightsquigarrow_P y.
\]

This relation is well-defined on equivalence classes.

It provides the structural ordering of transition components.

---

# 52. Quotient Transition Structure

The quotient state space is

\[
S/{\approx_P}.
\]

The induced transition is

\[
\overline{P}([x])
=
[P(x)].
\]

Because mutual reachability is preserved by deterministic transition,

\[
[x]=[y]
\implies
[P(x)]=[P(y)].
\]

Therefore the quotient transition is well-defined.

---

# 53. Reachability and SRM-0004

SRM-0004 defines

\[
P_{0:n}
=
P_{n-1}\circ\cdots\circ P_0.
\]

For a state \(S_0\),

\[
S_n=P_{0:n}(S_0).
\]

Therefore reachability in a composed transition sequence is

\[
S_0\rightsquigarrow S_n.
\]

SRM-0007 consequently extends composition into state-space reachability.

---

# 54. Reachability and SRM-0005

SRM-0005 establishes identity and invertibility.

The identity satisfies

\[
I_S(x)=x.
\]

Therefore every state is reachable from itself.

For an invertible operator,

\[
P^{-1}(P(x))=x.
\]

Thus backward reachability is uniquely defined along the inverse trajectory.

---

# 55. Reachability and SRM-0006

SRM-0006 establishes transition equivalence and conjugacy.

Suppose

\[
Q=\phi\circ P\circ\phi^{-1}.
\]

Then

\[
Q^n
=
\phi\circ P^n\circ\phi^{-1}.
\]

Therefore, if

\[
y=P^n(x),
\]

then

\[
\phi(y)=Q^n(\phi(x)).
\]

Hence conjugate systems preserve reachability structure.

---

# 56. Reachability Invariance Under Conjugacy

If \(P\) and \(Q\) are conjugate by a bijection

\[
\phi:S\to T,
\]

then

\[
x\rightsquigarrow_P y
\iff
\phi(x)\rightsquigarrow_Q\phi(y).
\]

Proof:

\[
y=P^n(x).
\]

Applying \(\phi\),

\[
\phi(y)=\phi(P^n(x)).
\]

By conjugacy,

\[
\phi(P^n(x))
=
Q^n(\phi(x)).
\]

Therefore,

\[
\phi(x)\rightsquigarrow_Q\phi(y).
\]

The converse follows using \(\phi^{-1}\).

---

# 57. Orbit Preservation Under Conjugacy

Under conjugacy,

\[
Q=\phi\circ P\circ\phi^{-1},
\]

we obtain

\[
\mathcal{O}_Q(\phi(x))
=
\phi(\mathcal{O}_P(x)).
\]

Thus conjugacy maps complete transition orbits bijectively.

---

# 58. Period Preservation Under Conjugacy

If

\[
P^k(x)=x,
\]

then

\[
Q^k(\phi(x))
=
\phi(P^k(x)).
\]

Therefore,

\[
Q^k(\phi(x))
=
\phi(x).
\]

Hence periodicity is preserved.

If \(k\) is the minimal period of \(x\), then it is also the minimal period of \(\phi(x)\).

Therefore conjugacy preserves periods.

---

# 59. Fixed-Point Preservation Under Conjugacy

If

\[
P(x)=x,
\]

then

\[
Q(\phi(x))
=
\phi(P(x))
=
\phi(x).
\]

Therefore,

\[
\phi(x)\in\operatorname{Fix}(Q).
\]

Thus conjugacy maps fixed points to fixed points.

---

# 60. Reachability Invariant

A property \(I\) of states is a reachability invariant if

\[
x\in I
\]

and

\[
x\rightsquigarrow_P y
\]

imply

\[
y\in I.
\]

Equivalently,

\[
P(I)\subseteq I.
\]

Therefore reachability invariants are positively invariant sets.

---

# 61. Orbit Invariant

A property is an orbit invariant if it has the same value on every state in an orbit.

Let

\[
J:S\to V
\]

be an observable.

Then \(J\) is invariant under \(P\) if

\[
J(P(x))=J(x)
\]

for every

\[
x\in S.
\]

Iteration gives

\[
J(P^n(x))=J(x)
\]

for all

\[
n\geq0.
\]

---

# 62. Invariant Level Sets

For a scalar invariant

\[
J:S\to\mathbb{R},
\]

the level set

\[
J^{-1}(c)
\]

is positively invariant whenever

\[
J(P(x))=J(x).
\]

Thus transition dynamics remain inside invariant observable levels.

---

# 63. Reachability Algorithm

Given \(x\in S\), the forward reachability procedure is:

1. initialize the current state to \(x\);
2. record the current state;
3. apply \(P\);
4. test whether the resulting state has already been encountered;
5. if not, record it;
6. repeat.

For a finite state space, termination occurs once a previously visited state is encountered.

---

# 64. Finite-State Orbit Decomposition

If

\[
|S|<\infty,
\]

then every forward orbit is eventually periodic.

Proof follows from the pigeonhole principle.

The sequence

\[
x,P(x),P^2(x),\ldots
\]

contains infinitely many terms but only finitely many possible states.

Therefore there exist

\[
m<n
\]

such that

\[
P^m(x)=P^n(x).
\]

Let

\[
k=n-m.
\]

Then

\[
P^{m+k}(x)=P^m(x).
\]

Thus the orbit is eventually periodic.

---

# 65. Finite-State Orbit Bound

For a finite state space with

\[
|S|=N,
\]

every forward trajectory contains at most \(N\) distinct states.

The transient length is bounded by

\[
N-1.
\]

The eventual cycle length is bounded by

\[
N.
\]

Thus the orbit decomposes into

\[
\text{transient length}+\text{cycle length}
\leq N.
\]

---

# 66. Orbit Detection

A runtime implementation may detect cycles by maintaining a visited-state set.

For each state \(S_i\), determine whether

\[
S_i\in V
\]

where \(V\) is the set of previously observed states.

If true, a repeated state has been detected.

If

\[
S_i=S_j
\]

with

\[
j<i,
\]

then the cycle length is

\[
i-j.
\]

---

# 67. State-Trace Representation

A transition trace may be represented as

\[
\mathcal{E}
=
(S_0,S_1,\ldots,S_n).
\]

For a deterministic transition,

\[
S_{i+1}=P(S_i).
\]

The trace is valid if every adjacent pair satisfies this transition relation.

---

# 68. Reachability Certification

A reachability claim

\[
x\rightsquigarrow_P y
\]

may be certified by a finite witness sequence

\[
(x,S_1,\ldots,S_n,y)
\]

such that

\[
S_{i+1}=P(S_i).
\]

The certificate therefore consists of:

- initial state;
- transition operator;
- finite iteration count;
- intermediate states;
- target state.

---

# 69. Minimal Reachability Witness

If

\[
y=P^n(x),
\]

and no smaller non-negative integer \(m<n\) satisfies

\[
P^m(x)=y,
\]

then \(n\) is the minimal reachability length from \(x\) to \(y\).

Define

\[
d_P(x,y)
=
\min\{n\geq0:P^n(x)=y\}
\]

when the set is nonempty.

This is a directed transition distance.

---

# 70. Transition Distance

The transition distance satisfies

\[
d_P(x,x)=0.
\]

If

\[
x\rightsquigarrow_P y
\]

and

\[
y\rightsquigarrow_P z,
\]

then

\[
d_P(x,z)
\leq
d_P(x,y)+d_P(y,z).
\]

Equality need not hold because a shorter transition path may exist.

---

# 71. Directed Nature of Transition Distance

For general non-invertible systems,

\[
d_P(x,y)
\neq
d_P(y,x)
\]

in general.

It is therefore not necessarily a metric.

It is a directed reachability measure.

If \(P\) is invertible and the orbit is periodic, directed distances may still depend on orientation.

---

# 72. Reachability Graph

Define the transition graph

\[
G_P=(V,E)
\]

with

\[
V=S
\]

and

\[
(x,y)\in E
\iff
y=P(x).
\]

Each state has exactly one outgoing transition edge under a deterministic operator.

A state may have multiple incoming edges when \(P\) is non-injective.

---

# 73. Orbit as a Graph Path

The orbit sequence

\[
x,P(x),P^2(x),\ldots
\]

is a directed path in \(G_P\).

Reachability corresponds to existence of a directed path.

Periodic orbits correspond to directed cycles.

Fixed points correspond to self-loops.

---

# 74. Functional Graph Structure

For a finite deterministic state space, the transition graph is a functional graph.

Each connected component contains exactly one directed cycle.

Every non-cycle state belongs to a directed transient path leading into that cycle.

Therefore every component has the structure

\[
\text{in-trees}\to\text{cycle}.
\]

---

# 75. Basin of Attraction

Let

\[
C\subseteq S
\]

be an invariant periodic orbit.

Its basin of attraction is

\[
\mathcal{B}(C)
=
\{x\in S:
\exists n\geq0,\ P^n(x)\in C\}.
\]

Thus the basin consists of every state that eventually reaches the periodic orbit.

---

# 76. Basin Invariance

If

\[
x\in\mathcal{B}(C),
\]

then

\[
P(x)\in\mathcal{B}(C).
\]

Proof:

There exists \(n\geq0\) such that

\[
P^n(x)\in C.
\]

Then

\[
P^{n-1}(P(x))\in C
\]

when \(n>0\), while for \(n=0\), \(x\in C\) and invariance gives \(P(x)\in C\).

Therefore the basin is positively invariant.

---

# 77. Reachability Kernel

For a target set

\[
A\subseteq S,
\]

define the reachability kernel

\[
\operatorname{Ker}_P(A)
=
\{x\in S:\operatorname{Reach}_P(x)\cap A\neq\varnothing\}.
\]

Equivalently,

\[
\operatorname{Ker}_P(A)
=
\bigcup_{n\geq0}P^{-n}(A).
\]

This is the set of states from which \(A\) is reachable.

---

# 78. Forward Reachability Operator

Define the operator

\[
\mathfrak{R}_P(A)
=
A\cup P(A).
\]

Repeated application gives

\[
\mathfrak{R}_P^n(A)
=
\bigcup_{k=0}^{n}P^k(A).
\]

The complete reachable closure is

\[
\operatorname{Reach}_P(A)
=
\bigcup_{n\geq0}\mathfrak{R}_P^n(A).
\]

---

# 79. Least Fixed Point Characterization

The reachable closure is the least fixed point of

\[
F(A)=A_0\cup P(A)
\]

containing the initial set \(A_0\).

Therefore,

\[
\operatorname{Reach}_P(A_0)
=
\operatorname{lfp}(F).
\]

This connects transition reachability with fixed-point semantics.

---

# 80. Reachability and Runtime Semantics

Let

\[
R_i
\]

be a runtime representation of state \(S_i\).

Let

\[
\operatorname{decode}(R_i)=S_i.
\]

Runtime correctness requires

\[
\operatorname{decode}(R_{i+1})
=
P(\operatorname{decode}(R_i)).
\]

Therefore,

\[
R_0\rightsquigarrow R_n
\]

must correspond to

\[
S_0\rightsquigarrow_P S_n.
\]

---

# 81. Reachability Preservation by Encoding

Let

\[
\phi:S\to R
\]

be a faithful state representation.

If

\[
\phi(P(x))
=
\widehat{P}(\phi(x)),
\]

then

\[
\phi(P^n(x))
=
\widehat{P}^n(\phi(x)).
\]

Therefore encoding preserves transition reachability.

---

# 82. Runtime Reachability Theorem

If the runtime implementation satisfies

\[
\operatorname{decode}(R_{i+1})
=
P(\operatorname{decode}(R_i))
\]

for every transition step, then every runtime trace corresponds to a valid mathematical transition trace.

Therefore,

\[
R_0\rightsquigarrow_{\widehat P}R_n
\implies
\operatorname{decode}(R_0)
\rightsquigarrow_P
\operatorname{decode}(R_n).
\]

# 83. Orbit Certification

An orbit certificate consists of:

\[
(x,P,P^0(x),P^1(x),\ldots,P^n(x)).
\]

For each index,

\[
P(P^i(x))=P^{i+1}(x).
\]

A verifier can therefore validate the entire finite orbit by checking adjacent transitions.

---

# 84. Period Certification

A period-\(k\) certificate for \(x\) requires

\[
P^k(x)=x
\]

and

\[
P^j(x)\neq x
\]

for

\[
0<j<k.
\]

This proves that \(k\) is the minimal period.

---

# 85. Fixed-Point Certification

A fixed-point certificate consists simply of

\[
P(x)=x.
\]

No iteration beyond one step is required.

---

# 89. Conjugacy Certification Contract

Q=\phi\circ P\circ\phi^{-1},

\phi^{-1}\circ\phi=I_S,

\phi\circ\phi^{-1}=I_T,

Once these identities hold, reachability and orbit structure are transported between the two systems.

# 90. Fundamental Reachability Theorem

For a deterministic transition operator

\[
P:S\to S,
\]

the following are equivalent for states \(x,y\in S\):

\[
x\rightsquigarrow_P y
\]

and

\[
\exists n\in\mathbb{N}_0:
y=P^n(x).
\]

Furthermore, if

\[
y=P^m(x)
\]

and

\[
z=P^n(y),
\]

then

\[
z=P^{m+n}(x).
\]

Therefore reachability is closed under transition composition.

---

# 91. Fundamental Orbit Theorem

For every state

\[
x\in S,

\mathcal{O}_P^+(x)
=
\{P^n(x):n\geq0\}

is positively invariant.

If \(P\) is invertible, the full orbit

\[
\mathcal{O}_P(x)
=
\{P^n(x):n\in\mathbb{Z}\}
\]

is invariant.

---

# 92. Fundamental Periodicity Theorem

If

\[
P^k(x)=x
\]

for some

\[
k>0,
\]

then

\[
P^{qk+r}(x)=P^r(x)
\]

for all integers

\[
q\geq0
\]

and

\[
0\leq r<k.
\]

Therefore the orbit is periodic with period dividing \(k\).

---

# 93. Fundamental Conjugacy Theorem

Let

\[
P:S\to S
\]

and

\[
Q:T\to T
\]

be conjugate through a bijection

\[
\phi:S\to T.
\]

Then

\[
Q^n=\phi\circ P^n\circ\phi^{-1}.
\]

Consequently,

\[
x\rightsquigarrow_P y
\iff
\phi(x)\rightsquigarrow_Q\phi(y).
\]

Moreover,

\[
\phi(\mathcal{O}_P(x))
=
\mathcal{O}_Q(\phi(x)).
\]
