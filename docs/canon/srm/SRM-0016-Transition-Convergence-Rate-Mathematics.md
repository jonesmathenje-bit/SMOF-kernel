## 1. Purpose

This specification defines the mathematical framework by which the rate of convergence of a state transition process is represented, classified, bounded, compared, and certified within the State-Manifold Operator Framework.

A transition may converge without converging at a uniform rate. Therefore, the statement

[
x_k\to x^\ast
]

is insufficient to characterize the computational, dynamical, geometric, or analytical behavior of a transition.

The present specification introduces rate-sensitive structures for trajectories generated by transition operators.

The fundamental transition is

[
x_{k+1}=T_k(x_k),
]

or, in the autonomous case,

[
x_{k+1}=T(x_k).
]

Let (x^\ast) denote a limiting state, equilibrium, invariant state, or target state. Define the transition error by

[
e_k=x_k-x^\ast
]

whenever subtraction is defined in the relevant local representation.

Convergence-rate mathematics studies the asymptotic and finite-stage behavior of

[
|e_k|.
]

---

## 2. Constitutional Position

Transition convergence rates belong to the analytical and dynamical interpretation of the SMOF runtime.

A convergence-rate statement requires:

1. a state space;
2. a transition operator or transition sequence;
3. a reference state, set, orbit, or invariant object;
4. an error or distance representation;
5. an asymptotic or finite-horizon comparison criterion.

Thus convergence-rate mathematics does not define the existence of a transition. Rather, it quantifies how rapidly the transition approaches its designated limiting structure.

The canonical dependency chain is

[
\text{State}
\rightarrow
\text{Transition}
\rightarrow
\text{Error}
\rightarrow
\text{Convergence}
\rightarrow
\text{Rate}
\rightarrow
\text{Certificate}.
]

---

## 3. Transition Sequence

Let

[
{x_k}_{k\geq 0}
]

be a sequence of states generated by

[
x_{k+1}=T_k(x_k).
]

For an autonomous transition,

[
T_k=T,
]

so that

[
x_k=T^{(k)}(x_0),
]

where

[
T^{(k)}

\underbrace{T\circ T\circ\cdots\circ T}_{k\text{ times}}.
]

For a non-autonomous transition,

[
x_k
=

T_{k-1}\circ\cdots\circ T_1\circ T_0(x_0).
]

Convergence-rate analysis may therefore concern either a single repeated operator or a time-dependent operator sequence.

---

## 4. Reference Object

The limiting object need not always be a single point.

Possible reference objects include:

[
x^\ast,
]

a fixed point;

[
\mathcal A,
]

an invariant set;

[
\Gamma,
]

a periodic orbit;

or

[
\mathcal M,
]

an invariant manifold.

For a point reference,

[
e_k=x_k-x^\ast.
]

For a set reference, the natural error measure is

[
e_k=d(x_k,\mathcal A),
]

where

[
d(x,\mathcal A)
=

\inf_{a\in\mathcal A}d(x,a).
]

The convergence-rate framework is therefore formulated in terms of a general nonnegative error quantity

[
E_k\geq 0.
]

---

## 5. Fundamental Error Sequence

Let

[
E_k=\mathcal E(x_k,\mathcal R),
]

where (\mathcal R) is the reference object and

[
\mathcal E
]

is a valid error functional.

The fundamental convergence condition is

[
\lim_{k\to\infty}E_k=0.
]

The convergence rate describes the manner in which this limit is approached.

A rate statement generally compares (E_k) with a reference sequence

[
\rho_k\to 0.
]

---

## 6. Rate Comparison

The error sequence is said to be bounded by the comparison sequence (\rho_k) if there exists (C>0) and (k_0\geq 0) such that

[
E_k\leq C\rho_k
]

for all

[
k\geq k_0.
]

This relation may be written as

[
E_k=O(\rho_k).
]

If

[
\limsup_{k\to\infty}\frac{E_k}{\rho_k}<\infty,
]

then the same asymptotic upper-rate relation holds.

If

[
\lim_{k\to\infty}\frac{E_k}{\rho_k}=0,
]

then

[
E_k=o(\rho_k).
]

---

## 7. Asymptotic Rate Classes

The principal convergence-rate classes are:

[
\text{finite-time},
]

[
\text{superlinear},
]

[
\text{quadratic},
]

[
\text{order-}p,
]

[
\text{linear},
]

[
\text{sublinear},
]

[
\text{polynomial},
]

and

[
\text{logarithmic or slower}.
]

These classifications are not mutually exclusive at every level of description. For example, quadratic convergence is a particular order-(p) convergence with

[
p=2.
]

---

## 8. Q-Linear Convergence

The sequence ({x_k}) converges Q-linearly to (x^\ast) if there exists

[
q\in(0,1)
]

such that

[
\limsup_{k\to\infty}
\frac{E_{k+1}}{E_k}
\leq q.
]

Equivalently, for sufficiently large (k),

[
E_{k+1}\leq qE_k.
]

Repeated application gives

[
E_k
\leq
q^{k-k_0}E_{k_0}.
]

Thus the error decreases geometrically.

---

## 9. R-Linear Convergence

The sequence converges R-linearly if there exists a positive sequence ({a_k}) and constants

[
C>0,
\qquad
q\in(0,1),
]

such that

[
E_k\leq a_k
]

and

[
a_k\leq Cq^k.
]

R-linear convergence is weaker than Q-linear convergence.

The distinction is important because an error sequence may be bounded by a geometric sequence without possessing a uniform one-step contraction ratio.

---

## 10. Superlinear Convergence

The transition converges Q-superlinearly when

[
\lim_{k\to\infty}
\frac{E_{k+1}}{E_k}
=

0.

]

Equivalently,

[
E_{k+1}=o(E_k).
]

The error reduction factor therefore improves asymptotically.

For sufficiently large (k), the convergence eventually exceeds every fixed linear contraction rate.

---

## 11. Quadratic Convergence

Quadratic convergence occurs when there exists (C>0) such that

[
E_{k+1}
\leq
CE_k^2
]

for sufficiently large (k).

More generally, if

[
\limsup_{k\to\infty}
\frac{E_{k+1}}{E_k^2}
<\infty,
]

the transition is asymptotically quadratically convergent.

Quadratic convergence implies superlinear convergence whenever

[
E_k\to0.
]

---

## 12. Order-(p) Convergence

For

[
p>1,
]

the transition is said to converge with order (p) if

[
\lim_{k\to\infty}
\frac{E_{k+1}}{E_k^p}
=

C
]

for some finite constant

[
C>0.
]

The special cases include:

[
p=1
]

for linear convergence,

and

[
p=2
]

for quadratic convergence.

---

## 13. Sublinear Convergence

Sublinear convergence occurs when

[
E_k\to0
]

but

[
\lim_{k\to\infty}
\frac{E_{k+1}}{E_k}
=

1.

]

A common example is

[
E_k=O(k^{-\alpha}),
]

where

[
\alpha>0.
]

Sublinear convergence may still be mathematically guaranteed, but the number of transition steps required to achieve a prescribed tolerance can be substantially greater than under geometric convergence.

---

## 14. Finite-Time Convergence

A transition has finite-time convergence if there exists

[
N<\infty
]

such that

[
E_k=0
]

for all

[
k\geq N.
]

Equivalently,

[
x_k=x^\ast
]

for all sufficiently large (k) in the point-reference case.

Finite-time convergence is stronger than asymptotic convergence.

---

## 15. Exponential Convergence

The transition converges exponentially if there exist constants

[
C>0,
\qquad
\alpha>0,
]

such that

[
E_k
\leq
Ce^{-\alpha k}.
]

Setting

[
q=e^{-\alpha},
]

gives

[
0<q<1,
]

and therefore

[
E_k\leq Cq^k.
]

Discrete exponential convergence and geometric convergence are therefore equivalent descriptions under this parametrization.

---

## 16. Convergence Rate Function

Define the instantaneous ratio

[
r_k
=

\frac{E_{k+1}}{E_k},
]

whenever

[
E_k>0.
]

The sequence ({r_k}) is the local convergence-rate sequence.

If

[
r_k\leq q<1,
]

the transition contracts at stage (k).

If

[
r_k\to q\in(0,1),
]

the asymptotic behavior is Q-linear.

If

[
r_k\to0,
]

the convergence is superlinear.

If

[
r_k\to1,
]

the convergence may be sublinear.

---

## 17. Logarithmic Decay Rate

Define

[
\lambda_k
=

-\frac{1}{k}\log\left(\frac{E_k}{E_0}\right),
]

provided

[
E_k>0.
]

If

[
\lambda_k\to\lambda>0,
]

then the error has asymptotic exponential decay rate (\lambda).

The corresponding contraction factor is

[
q=e^{-\lambda}.
]

---

## 18. Lyapunov-Induced Convergence Rate

Let

[
V:\mathcal X\to\mathbb R_{\geq0}
]

be a Lyapunov function satisfying

[
\alpha_1(E_k)
\leq
V(x_k)
\leq
\alpha_2(E_k),
]

where

[
\alpha_1,
\alpha_2
]

are positive comparison functions.

Suppose

[
V(x_{k+1})
\leq
qV(x_k),
\qquad
0<q<1.
]

Then

[
V(x_k)
\leq
q^kV(x_0).
]

If the comparison functions are quadratic,

[
c_1E_k^2
\leq
V(x_k)
\leq
c_2E_k^2,
]

then

[
E_k
\leq
\sqrt{\frac{c_2}{c_1}}
q^{k/2}E_0.
]

Thus Lyapunov decrease provides an explicit convergence-rate certificate.

---

## 19. Local Linearization

Let

[
x^\ast=T(x^\ast)
]

be a fixed point.

Near (x^\ast), write

[
x_k=x^\ast+e_k.
]

Then

[
e_{k+1}

T(x^\ast+e_k)-T(x^\ast).
]

If (T) is differentiable,

[
e_{k+1}

DT(x^\ast)e_k+R(e_k),
]

where

[
\frac{|R(e_k)|}{|e_k|}
\to0.
]

The local convergence rate is therefore governed to first order by the Jacobian

[
A=DT(x^\ast).
]

---

## 20. Spectral Radius Criterion

Let

[
\rho(A)
]

denote the spectral radius of

[
A=DT(x^\ast).
]

If

[
\rho(A)<1,
]

then the fixed point is locally asymptotically stable and the local transition is geometrically convergent under the standard differentiability assumptions.

The dominant asymptotic linear rate is determined by

[
\rho(A).
]

When the dominant eigenstructure is nondegenerate, one expects asymptotically

[
E_k\approx C\rho(A)^k.
]

---

## 21. Dominant Mode

Suppose the linearized transition is

[
e_{k+1}=Ae_k.
]

If

[
A
=

P\Lambda P^{-1},
]

then

[
e_k
=

P\Lambda^kP^{-1}e_0.
]

The slowest-decaying mode corresponds to eigenvalues satisfying

[
|\lambda|=\rho(A).
]

These modes dominate the asymptotic convergence behavior.

---

## 22. Non-Normal Transitions

The spectral radius alone does not fully characterize finite-stage convergence when (A) is non-normal.

Even if

[
\rho(A)<1,
]

it may occur that

[
|A^k|
]

initially increases before asymptotic decay begins.

Therefore the distinction must be maintained between:

[
\text{asymptotic rate},
]

and

[
\text{transient amplification}.
]

A complete convergence certificate may require both.

---

## 23. Operator Norm Bound

If there exists a norm such that

[
|DT(x)|
\leq
q<1
]

throughout a neighborhood (\mathcal U), then

[
|T(x)-T(y)|
\leq
q|x-y|
]

for all relevant

[
x,y\in\mathcal U.
]

Consequently,

[
E_k
\leq
q^kE_0.
]

This provides a direct uniform linear convergence certificate.

---

## 24. Variable Contraction Rate

Suppose

[
E_{k+1}
\leq
q_kE_k,
]

where

[
0\leq q_k<1.
]

Then

[
E_k
\leq
\left(
\prod_{j=0}^{k-1}q_j
\right)E_0.
]

Therefore convergence occurs whenever

[
\prod_{j=0}^{\infty}q_j=0.
]

The convergence rate is determined by the decay of this product.

---

## 25. Average Contraction

Taking logarithms gives

[
\log E_k
\leq
\log E_0
+
\sum_{j=0}^{k-1}\log q_j.
]

Define the average logarithmic contraction by

[
\bar\lambda_k
=

-\frac{1}{k}
\sum_{j=0}^{k-1}\log q_j.
]

Then

[
E_k
\leq
E_0e^{-k\bar\lambda_k}.
]

If

[
\liminf_{k\to\infty}\bar\lambda_k>0,
]

the transition converges exponentially.

---

## 26. Continuous-Time Correspondence

For a continuous trajectory satisfying

[
\dot x=f(x),
]

with exponentially stable equilibrium (x^\ast),

[
|x(t)-x^\ast|
\leq
Ce^{-\alpha t}|x(0)-x^\ast|.
]

A discrete transition with step size (h) may inherit the approximate form

[
E_k
\leq
Ce^{-\alpha kh}E_0.
]

Thus the discrete convergence factor is

[
q_h=e^{-\alpha h}.
]

---

## 27. Convergence to an Invariant Set

Let (\mathcal A) be invariant under (T).

Define

[
E_k=d(x_k,\mathcal A).
]

The transition converges linearly to (\mathcal A) if

[
d(x_{k+1},\mathcal A)
\leq
qd(x_k,\mathcal A),
\qquad
0<q<1.
]

Then

[
d(x_k,\mathcal A)
\leq
q^kd(x_0,\mathcal A).
]

---

## 28. Periodic Transitions

Suppose the transition is periodic with period (p):

[
T_{k+p}=T_k.
]

Define the period map

[
\Pi
=

T_{p-1}\circ\cdots\circ T_0.
]

Convergence over complete periods is governed by

[
x_{(m+1)p}
=

\Pi(x_{mp}).
]

The convergence rate of the periodic transition can therefore be analyzed through the rate properties of (\Pi).

---

## 29. Switched Transition Rates

Consider

[
x_{k+1}=T_{\sigma(k)}(x_k),
]

where

[
\sigma(k)
]

is a switching signal.

Suppose each transition satisfies

[
E_{k+1}
\leq
q_{\sigma(k)}E_k.
]

Then

[
E_k
\leq
\prod_{j=0}^{k-1}q_{\sigma(j)}E_0.
]

Uniform convergence follows if

[
\sup_iq_i<1.
]

More general convergence conditions may be formulated using average dwell time or joint spectral quantities.

---

## 30. Perturbed Convergence Recurrence

Suppose

[
E_{k+1}
\leq
qE_k+\eta_k,
\qquad
0<q<1.
]

Iterating gives

[
E_k
\leq
q^kE_0
+
\sum_{j=0}^{k-1}
q^{k-1-j}\eta_j.
]

This equation separates:

[
\text{nominal convergence},
]

from

[
\text{perturbation-driven residual behavior}.
]

---

## 31. Vanishing Perturbations

If

[
\eta_k\to0,
]

then the perturbation contribution may also converge to zero under suitable boundedness conditions.

If, additionally,

[
\eta_k=O(r^k),
]

then the resulting convergence rate is determined by the slower of

[
q
]

and

[
r.
]

Thus

[
E_k
=

O\left(\max{q,r}^k\right)
]

in the generic case.

---

## 32. Persistent Perturbations

If

[
\eta_k\leq\bar\eta,
]

then

[
E_k
\leq
q^kE_0
+
\bar\eta
\frac{1-q^k}{1-q}.
]

Therefore

[
\limsup_{k\to\infty}E_k
\leq
\frac{\bar\eta}{1-q}.
]

The transition converges to a neighborhood rather than necessarily to the exact reference state.

---

## 33. Robust Convergence Rate

A robust convergence certificate requires constants

[
q\in(0,1),
\qquad
C\geq1,
]

such that for all admissible perturbations,

[
E_k
\leq
Cq^kE_0+\mathcal R_k,
]

where

[
\mathcal R_k
]

is a quantified perturbation residual.

Robustness therefore modifies the convergence statement from exact asymptotic decay to controlled decay under admissible uncertainty.

---

## 34. Rate Degradation

Let

[
q_0
]

denote the nominal contraction factor and

[
q_\delta
]

the perturbed factor.

The rate degradation is

[
\Delta q
=

q_\delta-q_0.
]

A robust transition preserves convergence if

[
q_\delta<1.
]

The convergence-rate margin is therefore

[
\mu
=

1-q_\delta.
]

Larger (\mu) indicates greater tolerance against rate degradation.

---

## 35. Convergence-Time Estimate

Suppose

[
E_k\leq Cq^kE_0,
\qquad
0<q<1.
]

For a tolerance

[
\varepsilon>0,
]

we require

[
Cq^kE_0\leq\varepsilon.
]

Taking logarithms yields

[
k
\geq
\frac{
\log(\varepsilon/(CE_0))
}{
\log q
}.
]

Since

[
\log q<0,
]

the inequality is interpreted with the corresponding sign reversal already incorporated by the ratio.

The minimum integer transition count is

[
N_\varepsilon
=

\left\lceil
\frac{
\log(\varepsilon/(CE_0))
}{
\log q
}
\right\rceil.
]

---

## 36. Superlinear Iteration Count

Suppose

[
E_{k+1}
\leq
CE_k^p,
\qquad
p>1.
]

Taking logarithms gives

[
\log E_{k+1}
\leq
\log C
+
p\log E_k.
]

The logarithmic error magnitude therefore grows approximately geometrically with exponent (p), explaining the rapid terminal phase of higher-order convergence.

---

## 37. Asymptotic Convergence Factor

Define

[
R
=

\limsup_{k\to\infty}
E_k^{1/k}.
]

Then:

[
R<1
]

indicates R-linear convergence,

[
R=0
]

is compatible with superlinear convergence,

and

[
R=1
]

indicates convergence no faster than subgeometric in this root-test sense.

The quantity (R) is the asymptotic convergence factor.

---

## 38. Rate Exponent

Define

[
\gamma
=

-\limsup_{k\to\infty}
\frac{1}{k}\log E_k.
]

If

[
\gamma>0,
]

the convergence is exponentially fast.

If

[
\gamma=0,
]

the transition may still converge, but not at a strictly positive exponential rate.

---

## 39. Cauchy Transition Rate

A transition may be analyzed without prior knowledge of the limiting state by considering

[
D_k
=

d(x_{k+1},x_k).
]

If

[
D_k
\leq
Cq^k,
]

then, in a complete metric space,

[
\sum_{k=0}^{\infty}D_k
]

converges.

Hence ({x_k}) is Cauchy and converges.

Moreover,

[
d(x_k,x^\ast)
\leq
\sum_{j=k}^{\infty}D_j
\leq
\frac{Cq^k}{1-q}.
]

Thus step-size decay can certify state convergence rate.

---

## 40. Residual-Based Rate

Suppose a target equation is

[
F(x)=0.
]

Define the residual

[
R_k=|F(x_k)|.
]

Residual convergence is not automatically identical to state convergence. A local regularity condition is required to relate

[
R_k
]

to

[
E_k.
]

If constants

[
c_1,c_2>0
]

satisfy

[
c_1E_k
\leq
R_k
\leq
c_2E_k,
]

then residual and state errors possess equivalent local convergence rates.

---

## 41. Rate of Operator Iteration

For a transition operator (T), define the (k)-stage convergence operator by

[
\mathcal C_k(x)
=

T^{(k)}(x)-x^\ast.
]

A uniform convergence-rate bound on a domain (\mathcal U) is

[
|\mathcal C_k(x)|
\leq
Cq^k|x-x^\ast|
]

for all

[
x\in\mathcal U.
]

This defines operator-level exponential convergence.

---

## 42. Uniform Convergence Rate

A family of transitions

[
{T_\theta}_{\theta\in\Theta}
]

has a uniform convergence rate if there exist

[
C>0,
\qquad
q\in(0,1),
]

independent of (\theta), such that

[
E_k(\theta)
\leq
Cq^kE_0(\theta)
]

for every admissible parameter.

Uniformity is stronger than pointwise convergence.

---

## 43. Parameter-Dependent Rates

For parameter (\theta), let

[
q=q(\theta).
]

Then

[
E_k(\theta)
\leq
C(\theta)q(\theta)^kE_0.
]

The rate sensitivity is described by

[
\frac{\partial q}{\partial\theta}
]

when differentiability exists.

Near a critical parameter where

[
q(\theta)\to1,
]

convergence becomes arbitrarily slow.

---

## 44. Critical Slowing Down

A family of transitions exhibits critical slowing down when

[
q(\theta)\uparrow1
]

as

[
\theta\to\theta_c.
]

The convergence time

[
N_\varepsilon
]

then diverges for fixed tolerance and initial error scale.

This phenomenon links convergence-rate mathematics to bifurcation and stability-boundary analysis.

---

## 45. Manifold Coordinates

Let (\mathcal M) be a smooth manifold and

[
x_k\in\mathcal M.
]

Because global subtraction may not be defined, the error may be represented through:

[
d_{\mathcal M}(x_k,x^\ast),
]

or through a local chart

[
\varphi:\mathcal U\to\mathbb R^n.
]

Then

[
E_k
=

|\varphi(x_k)-\varphi(x^\ast)|.
]

The convergence-rate definition must be invariant under admissible changes of local representation.

---

## 46. Coordinate Equivalence

Suppose two local norms satisfy

[
c_1|v|_a
\leq
|v|_b
\leq
c_2|v|_a.
]

Then geometric convergence in one norm implies geometric convergence in the other.

Specifically, if

[
E_k^{(a)}
\leq
Cq^k,
]

then

[
E_k^{(b)}
\leq
c_2Cq^k.
]

Thus the asymptotic linear factor is preserved under equivalent norms.

---

## 47. Metric Dependence

Although equivalent metrics preserve broad convergence classes, finite-stage numerical rate constants may depend strongly on the selected metric.

Therefore every quantitative rate certificate must identify:

1. the metric or norm;
2. the reference object;
3. the valid domain;
4. the transition family;
5. the rate constants.

A rate constant without its measurement structure is not a complete mathematical certificate.

---

## 48. Rate Certificate

A canonical convergence-rate certificate is represented by the tuple

[
\mathfrak C_{\mathrm{rate}}
=

(
\mathcal X,
\mathcal R,
\mathcal E,
T,
\mathcal U,
C,
q,
k_0,
\mathcal A
),
]

where:

[
\mathcal X
]

is the state space;

[
\mathcal R
]

is the reference object;

[
\mathcal E
]

is the error functional;

[
T
]

is the transition operator or transition family;

[
\mathcal U
]

is the validity domain;

[
C
]

is the prefactor;

[
q
]

is the convergence factor;

[
k_0
]

is the validity index;

and

[
\mathcal A
]

contains assumptions and admissibility conditions.

The certificate asserts

[
E_k
\leq
Cq^{k-k_0}E_{k_0}
]

for all admissible

[
k\geq k_0.
]

---

## 49. Higher-Order Rate Certificate

For order-(p) convergence, define

[
\mathfrak C_p
=

(
\mathcal X,
\mathcal R,
\mathcal E,
T,
\mathcal U,
C,
p,
k_0,
\mathcal A
).
]

The certificate asserts

[
E_{k+1}
\leq
