**System:** SMOF Kernel

## 1. Purpose

SRM-0012 defines the mathematics of stability regions for the SMOF transition system.

The specification establishes a formal relationship between:

* states;
* transition operators;
* trajectories;
* perturbations;
* invariant sets;
* attractors;
* stability properties;
* neighborhoods;
* basins;
* local stability regions;
* global stability regions;
* forward-invariant regions; and
* certified regions of admissible transition behavior.

The purpose of this specification is to transform the qualitative statement

> "states in this region remain stable under the transition dynamics"

into a mathematically defined property of the SMOF runtime.

SRM-0012 therefore extends the stability mathematics established by SRM-0011 from individual states, trajectories, and invariant structures to subsets of the state space.

---

This specification governs the mathematical definition of stability regions associated with a SMOF transition system.

It covers:

## 3. Mathematical Setting

Let the SMOF state space be

[
S.
]

Let a transition operator be

[
T:S\rightarrow S.
]

For an initial state

[
x_0\in S,
]

the forward trajectory is defined by

[
x_{n+1}=T(x_n),
\qquad n\geq 0.
]

Equivalently,

[
x_n=T^n(x_0).
]

The trajectory generated by (x_0) is

[
\mathcal{O}^{+}(x_0)
====================

{T^n(x_0):n\in\mathbb{N}_0}.
]

Let

[
d:S\times S\rightarrow [0,\infty)
]

be a metric when the state space admits a metric structure.

More generally, when a metric is unavailable, stability may be expressed using a topology, uniformity, norm, seminorm, or other admissible notion of proximity.

---

## 4. Definitions

### 4.1 Stability Property

A state (x\in S) is stable with respect to a specified stability criterion if sufficiently small perturbations of (x) produce trajectories satisfying the corresponding stability requirement.

The precise state-level stability property is inherited from SRM-0011.

---

### 4.2 Stability Region

Let

[
\mathcal{R}\subseteq S.
]

The set (\mathcal{R}) is a stability region if every state in (\mathcal{R}) satisfies the specified stability criterion under the transition dynamics.

Thus,

[
x\in\mathcal{R}
\Longrightarrow
\operatorname{Stable}(x).
]

The stability region is therefore a subset of the state space rather than a property of a single state.

---

### 4.3 Stable-State Set

Define the stable-state set by

[
\operatorname{Stab}(T)
======================

{x\in S:\operatorname{Stable}_T(x)}.
]

Every stability region is a subset of the stable-state set:

[
\mathcal{R}\subseteq\operatorname{Stab}(T).
]

The maximal stability region under a given stability definition is therefore

[
\mathcal{R}_{\max}
==================

\operatorname{Stab}(T).
]

---

### 4.4 Local Stability Region

A local stability region of a state (x^\ast) is a neighborhood

[
U\subseteq S
]

containing (x^\ast) such that every state in (U) satisfies the prescribed stability condition.

Thus,

[
x^\ast\in U
]

and

[
\forall x\in U,
\quad
\operatorname{Stable}_T(x).
]

---

### 4.5 Global Stability Region

A global stability region is a subset (\mathcal{R}\subseteq S) for which the stability criterion holds throughout the entire region without restricting the initial state to a smaller neighborhood.

If

[
\mathcal{R}=S,
]

then the system is globally stable with respect to the specified criterion.

---

## 5. Region Stability

Let

[
\mathcal{R}\subseteq S.
]

A region is stable if the stability property holds uniformly or pointwise throughout the region according to the selected stability definition.

The weakest pointwise requirement is

[
\forall x\in\mathcal{R},
\quad
\operatorname{Stable}_T(x).
]

A stronger uniform requirement introduces common stability parameters.

Let

[
\varepsilon>0.
]

Suppose there exists

[
\delta>0
]

such that for every

[
x\in\mathcal{R}
]

and every perturbation (y\in S),

[
d(x,y)<\delta
]

implies

[
d(T^n(x),T^n(y))<\varepsilon
]

for all

[
n\geq0.
]

Then (\mathcal{R}) possesses uniform stability with parameters ((\varepsilon,\delta)).

---

## 6. Uniform Stability Region

A region (\mathcal{R}) is uniformly stable if

[
\forall\varepsilon>0,
\exists\delta>0
]

such that

[
x\in\mathcal{R},
\quad
d(x,y)<\delta
]

implies

[
d(T^n(x),T^n(y))<\varepsilon
]

for every

[
n\geq0.
]

The crucial property is that the same (\delta) applies to every (x\in\mathcal{R}).

This distinguishes uniform region stability from pointwise stability.

---

## 7. Forward-Invariant Region

A region

[
\mathcal{R}\subseteq S
]

is forward invariant under (T) if

[
T(\mathcal{R})\subseteq\mathcal{R}.
]

Equivalently,

[
x\in\mathcal{R}
\Longrightarrow
T(x)\in\mathcal{R}.
]

By induction,

[
T^n(\mathcal{R})\subseteq\mathcal{R}
]

for every

[
n\geq0.
]

Therefore every trajectory originating in (\mathcal{R}) remains inside (\mathcal{R}).

---

## 8. Positive Invariance

A region is positively invariant when

[
T^n(x)\in\mathcal{R}
]

for every

[
x\in\mathcal{R}
]

and every

[
n\in\mathbb{N}_0.
]

For a deterministic transition operator this is equivalent to

[
T(\mathcal{R})\subseteq\mathcal{R}.
]

---

## 9. Stable Forward-Invariant Region

A region (\mathcal{R}) is a stable forward-invariant region when both conditions hold:

[
T(\mathcal{R})\subseteq\mathcal{R}
]

and

[
\forall x\in\mathcal{R},
\quad
\operatorname{Stable}_T(x).
]

Such a region provides a mathematically controlled domain of transition evolution.

---

## 10. Strongly Stable Region

A region is strongly stable when stability and forward invariance are accompanied by a common perturbation bound.

There exists a function

[
\delta:(0,\infty)\rightarrow(0,\infty)
]

such that

[
\forall\varepsilon>0,
]

[
x\in\mathcal{R},
]

and

[
d(x,y)<\delta(\varepsilon)
]

imply

[
d(T^n(x),T^n(y))<\varepsilon
]

for all

[
n\geq0.
]

---

## 11. Neighborhood Stability

Let

[
x^\ast\in S.
]

For

[
r>0,
]

define the open ball

[
B_r(x^\ast)
===========

{x\in S:d(x,x^\ast)<r}.
]

If there exists (r>0) such that

[
B_r(x^\ast)
\subseteq
\operatorname{Stab}(T),
]

then (B_r(x^\ast)) is a local stability region around (x^\ast).

---

## 12. Closed Stability Region

A stability region

[
\mathcal{R}
]

is closed if

[
\overline{\mathcal{R}}=\mathcal{R}.
]

Closed regions are important when limiting states must remain admissible.

If a sequence

[
(x_n)
]

satisfies

[
x_n\in\mathcal{R}
]

and

[
x_n\rightarrow x,
]

then closedness guarantees

[
x\in\mathcal{R}.
]

---

## 13. Open Stability Region

A stability region is open if

[
\mathcal{R}=\operatorname{int}(\mathcal{R}).
]

Open stability regions naturally describe states having a nonzero neighborhood of admissible stable behavior.

---

## 14. Interior Stability

For an arbitrary stable-state set

[
\operatorname{Stab}(T),
]

its interior is

[
\operatorname{int}\operatorname{Stab}(T).
]

Every state in this interior possesses a neighborhood contained in the stable-state set.

Thus,

[
x\in\operatorname{int}\operatorname{Stab}(T)
]

implies the existence of (r>0) such that

[
B_r(x)\subseteq\operatorname{Stab}(T).
]

---

## 15. Stability Boundary

The boundary of a region (\mathcal{R}) is

[
\partial\mathcal{R}
===================

\overline{\mathcal{R}}
\setminus
\operatorname{int}(\mathcal{R}).
]

The stability boundary separates states satisfying the specified stability property from states outside the region.

Boundary states require separate analysis because arbitrarily small perturbations may move a state across the stability boundary.

---

## 16. Maximal Stability Region

Let (\mathfrak{S}) denote the family of all subsets of (S) satisfying a selected stability property.

A maximal stability region is a maximal element

[
\mathcal{R}_{\max}\in\mathfrak{S}
]

with respect to set inclusion.

Thus, there is no

[
\mathcal{R}'\in\mathfrak{S}
]

such that

[
\mathcal{R}_{\max}\subsetneq\mathcal{R}'.
]

---

## 17. Minimal Stability Region

A minimal stability region is a region satisfying the required stability property that contains no proper subset satisfying the same required property.

Thus,

[
\mathcal{R}_{\min}
]

satisfies

[
\operatorname{Stable}(\mathcal{R}_{\min})
]

while no proper subset has the required property.

Minimal regions are useful for certification and localized analysis.

---

## 18. Region Inclusion

Let

[
\mathcal{R}_1,\mathcal{R}_2\subseteq S.
]

If

[
\mathcal{R}_1\subseteq\mathcal{R}_2,
]

then (\mathcal{R}_1) is a refinement of (\mathcal{R}_2).

If (\mathcal{R}_2) is stable, (\mathcal{R}_1) inherits pointwise stability provided the stability property is defined pointwise.

---

## 19. Stability Under Intersection

Let

[
{\mathcal{R}*i}*{i\in I}
]

be a family of stable regions.

Their intersection is

[
\mathcal{R}
===========

\bigcap_{i\in I}\mathcal{R}_i.
]

If each stability property is preserved under restriction, then

[
\mathcal{R}
]

is also stable.

This provides a mathematical basis for combining multiple safety or stability constraints.

---

## 20. Stability Under Union

Let

[
\mathcal{R}_1,\mathcal{R}_2
]

be stable regions.

Their union is

[
\mathcal{R}_1\cup\mathcal{R}_2.
]

The union is pointwise stable whenever both regions satisfy the same stability property.

However, uniform stability of the union requires compatible uniform stability parameters.

Therefore,

[
\operatorname{Stable}(\mathcal{R}_1)
\land
\operatorname{Stable}(\mathcal{R}_2)
]

does not automatically imply uniform stability of the union unless the required common bounds exist.

---

## 21. Connected Stability Region

A stability region

[
\mathcal{R}
]

is connected if it cannot be represented as the union of two disjoint nonempty relatively open subsets.

Connectedness is relevant when a continuous transition family is interpreted over a single coherent stability domain.

---

## 22. Stability Components

If a stable-state set is disconnected, define its connected components by

[
\operatorname{Comp}(\operatorname{Stab}(T)).
]

Then

[
\operatorname{Stab}(T)
======================

\bigcup_{\alpha\in A}\mathcal{R}_\alpha
]

where each

[
\mathcal{R}_\alpha
]

is a maximal connected stable component.

---

## 23. Attraction Region

Let

[
A\subseteq S
]

be an attractor.

The attraction region of (A) is

[
\mathcal{B}(A)
==============

{x\in S:
\operatorname{dist}(T^n(x),A)\rightarrow0
}.
]

This is the basin of attraction associated with (A).

---

## 24. Basin of Attraction

For a metric state space,

[
\operatorname{dist}(x,A)
========================

\inf_{a\in A}d(x,a).
]

The basin of attraction is

[
\mathcal{B}(A)
==============

\left{
x\in S:
\lim_{n\rightarrow\infty}
\operatorname{dist}(T^n(x),A)=0
\right}.
]

When (A) is invariant, its basin is forward invariant under suitable continuity assumptions.

---

## 25. Stability Region of an Attractor

Let (A) be a stable attractor.

A stability region associated with (A) is a subset

[
\mathcal{R}_A\subseteq\mathcal{B}(A)
]

on which the specified stability criterion holds.

The relation between stability and attraction is therefore

[
\mathcal{R}_A
\subseteq
\mathcal{B}(A)
]

when the stability region is specifically defined as a stable subset of the attractor's basin.

---

## 26. Perturbation Stability Region

Let

[
\eta>0
]

be a perturbation bound.

Define

[
P_\eta(x)
=========

{y\in S:d(x,y)<\eta}.
]

A region (\mathcal{R}) is (\eta)-perturbation stable if

[
x\in\mathcal{R}
]

and

[
y\in P_\eta(x)
]

imply that the trajectories generated by (x) and (y) satisfy the specified stability criterion.

---

## 27. Robust Stability Region

A region is robustly stable if stability persists under a specified class of admissible perturbations.

Let

[
\mathcal{P}
]

be the family of admissible perturbation operators.

Then (\mathcal{R}) is robustly stable if

[
\forall P\in\mathcal{P},
\quad
\forall x\in\mathcal{R},
]

the perturbed trajectory satisfies the stability criterion.

---

## 28. Transition-Safe Region

A transition-safe region is a region

[
\mathcal{R}_{safe}\subseteq S
]

such that every admissible transition beginning within the region remains within the permitted stability and safety constraints.

At minimum,

[
T(\mathcal{R}*{safe})
\subseteq
\mathcal{R}*{safe}.
]

If perturbations are included, then for every admissible perturbation (P),

[
T_P(\mathcal{R}*{safe})
\subseteq
\mathcal{R}*{safe}.
]

---

## 29. Region Preservation

Let

[
f:S\rightarrow S
]

be a state transformation.

A region (\mathcal{R}) is preserved by (f) if

[
f(\mathcal{R})\subseteq\mathcal{R}.
]

For the transition operator,

[
T(\mathcal{R})\subseteq\mathcal{R}
]

is the fundamental preservation condition.

---

## 30. Exact Invariance

A region is exactly invariant if

[
T(\mathcal{R})=\mathcal{R}.
]

This is stronger than forward invariance:

[
T(\mathcal{R})=\mathcal{R}
\Longrightarrow
T(\mathcal{R})\subseteq\mathcal{R}.
]

If (T) is bijective, exact invariance implies invariance in both forward and backward time.

---

## 31. Backward-Invariant Region

If (T^{-1}) exists, a region (\mathcal{R}) is backward invariant when

[
T^{-1}(\mathcal{R})\subseteq\mathcal{R}.
]

Equivalently,

[
x\in\mathcal{R}
\Longrightarrow
T^{-1}(x)\in\mathcal{R}.
]

---

## 32. Bi-Invariant Stability Region

When (T) is invertible, a region is bi-invariant if

[
T(\mathcal{R})=\mathcal{R}
]

and

[
T^{-1}(\mathcal{R})=\mathcal{R}.
]

Such a region supports consistent forward and backward transition analysis.

---

## 33. Stability Region Hierarchy

Define the hierarchy

[
\mathcal{R}*{local}
\subseteq
\mathcal{R}*{stable}
\subseteq
\mathcal{R}*{robust}
\subseteq
\mathcal{R}*{global}
]

only when the corresponding definitions establish these inclusions.

The hierarchy is not assumed automatically.

Each inclusion must be justified by the relevant mathematical hypotheses.

---

## 34. Stability Region and Lyapunov Functions

Let

[
V:S\rightarrow\mathbb{R}
]

be a Lyapunov candidate.

A sublevel set is

[
\mathcal{R}_c
=============

{x\in S:V(x)\leq c}.
]

If

[
V(T(x))\leq V(x)
]

for all

[
x\in\mathcal{R}_c,
]

then

[
T(\mathcal{R}_c)
\subseteq
\mathcal{R}_c.
]

Therefore (\mathcal{R}_c) is forward invariant.

If the Lyapunov conditions of SRM-0011 establish stability on this region, then

[
\mathcal{R}_c
]

is a certified stability region.

---

## 35. Strict Lyapunov Decrease

If

[
V(T(x))<V(x)
]

for every

[
x\in\mathcal{R}_c\setminus A,
]

then the Lyapunov quantity strictly decreases outside the invariant set (A).

This provides a stronger basis for asymptotic stability and attraction.

---

## 36. Region of Lyapunov Stability

Define

[
\mathcal{R}_V
=============

{x\in S:
V(x)\leq c
}

]

for a permissible constant (c).

If the required Lyapunov inequalities hold throughout (\mathcal{R}_V), then (\mathcal{R}_V) is a Lyapunov-certified stability region.

---

## 37. Nested Stability Regions

Let

[
0<c_1<c_2.
]

For sublevel regions,

[
\mathcal{R}_{c_1}
=================

{x:V(x)\leq c_1}
]

and

[
\mathcal{R}_{c_2}
=================

{x:V(x)\leq c_2},
]

we obtain

[
\mathcal{R}*{c_1}
\subseteq
\mathcal{R}*{c_2}.
]

This produces a nested family of candidate stability regions.

---

## 38. Maximal Lyapunov Stability Region

Define

[
c^\ast
======

\sup
\left{
c>0:
\mathcal{R}_c
\text{ satisfies the required stability conditions}
\right}.
]

The corresponding maximal certified region is

[
\mathcal{R}_{c^\ast}
]

when the supremum is attained.

If it is not attained, the maximal certified region may instead be represented by the union

[
\bigcup_{c<c^\ast}\mathcal{R}_c.
]

---

## 39. Region Refinement

A stability region may be refined by introducing additional constraints.

Let

[
\mathcal{R}_1
]

be a stability region and let

[
C\subseteq S
]

be an admissibility constraint.

The refined region is

[
\mathcal{R}_2
=============

\mathcal{R}_1\cap C.
]

Then

[
\mathcal{R}_2\subseteq\mathcal{R}_1.
]

---

## 40. Multiple Stability Criteria

Suppose the system must satisfy stability criteria

[
C_1,C_2,\ldots,C_k.
]

Define

[
\mathcal{R}_i
=============

{x\in S:C_i(x)}.
]

The jointly certified region is

[
\mathcal{R}
===========

\bigcap_{i=1}^{k}\mathcal{R}_i.
]

Therefore,

[
x\in\mathcal{R}
]

if and only if

[
C_i(x)
]

holds for every

[
i\in{1,\ldots,k}.
]

---

## 41. Region Constraint Operator

Define a region constraint operator

[
\Gamma_C:\mathcal{P}(S)\rightarrow\mathcal{P}(S)
]

by

[
\Gamma_C(\mathcal{R})
=====================

{x\in\mathcal{R}:C(x)}.
]

Repeated constraint application gives

[
\mathcal{R}_{k}
===============

\Gamma_{C_k}\circ\cdots\circ\Gamma_{C_1}(S).
]

This provides a formal mechanism for constructing certified stability regions.

---

## 42. Region Closure

For a region (\mathcal{R}),

[
\overline{\mathcal{R}}
]

denotes its closure.

If stability is preserved under limits, the closure may itself form a stability region.

This must be established rather than assumed.

---

## 43. Region Interior

The interior

[
\operatorname{int}(\mathcal{R})
]

contains every state for which a neighborhood exists entirely inside (\mathcal{R}).

Interior stability is therefore stronger than mere membership at a boundary state when robustness against perturbation is required.

---

## 44. Region Boundary and Robustness

If

[
x\in\partial\mathcal{R},
]

then every neighborhood of (x) intersects both

[
\mathcal{R}
]

and its complement under standard separation assumptions.

Consequently, boundary states require explicit perturbation analysis.

---

## 45. Distance to Stability Boundary

For

[
x\in\mathcal{R},
]

define the stability-boundary distance by

[
\rho_{\mathcal{R}}(x)
=====================

\inf_{y\notin\mathcal{R}}d(x,y).
]

If

[
\rho_{\mathcal{R}}(x)>0,
]

then the state possesses a nonzero metric margin before leaving the region.

---

## 46. Stability Margin

Define the stability margin of (x) with respect to (\mathcal{R}) as

[
M_{\mathcal{R}}(x)
==================

\rho_{\mathcal{R}}(x).
]

A larger value indicates a larger geometric margin from the stability boundary.

The margin is relative to the selected metric.

---

## 47. Minimum Region Stability Margin

For a region (\mathcal{R}), define

[
M_{\min}(\mathcal{R})
=====================

\inf_{x\in\mathcal{R}}M_{\mathcal{R}}(x).
]

If

[
M_{\min}(\mathcal{R})>0,
]

the region possesses a uniform positive distance from its exterior under the specified assumptions.

---

## 48. Transition Amplification

Let perturbations be measured by

[
d(x,y).
]

Define the (n)-step amplification ratio

[
A_n(x,y)
========

\frac{d(T^n(x),T^n(y))}
{d(x,y)}
]

whenever

[
d(x,y)\neq0.
]

This quantity measures the relative amplification of an initial perturbation.

---

## 49. Region Amplification Bound

A region (\mathcal{R}) admits an (n)-step amplification bound (K_n) if

[
A_n(x,y)\leq K_n
]

for all admissible

[
x\in\mathcal{R}
]

and perturbations (y).

A uniform bound

[
K_n\leq K
]

provides a stronger regional stability statement.

---

## 50. Finite-Horizon Stability Region

For a finite horizon

[
N\in\mathbb{N},
]

define

[
\mathcal{R}_N
=============

\left{
x\in S:
\text{the required stability condition holds for }
0\leq n\leq N
\right}.
]

The finite-horizon regions satisfy

[
\mathcal{R}_{N+1}
\subseteq
\mathcal{R}_N
]

whenever the same criterion is extended by one additional transition.

---

## 51. Infinite-Horizon Stability Region

Define

[
\mathcal{R}_{\infty}
====================

\bigcap_{N=0}^{\infty}\mathcal{R}_N.
]

Then

[
x\in\mathcal{R}_{\infty}
]

if and only if the required stability property holds for every finite transition horizon.

---

## 52. Finite-to-Infinite Stability

Finite-horizon stability does not by itself imply infinite-horizon stability.

The implication

[
\forall N,\quad x\in\mathcal{R}*N
\Longrightarrow
x\in\mathcal{R}*{\infty}
]

requires the definition

[
\mathcal{R}_{\infty}
====================

\bigcap_N\mathcal{R}_N.
]

Certification must therefore distinguish finite-horizon evidence from infinite-horizon mathematical claims.

---

## 53. Region of Uniform Stability

Define

[
\mathcal{R}_{unif}
==================

\left{
x\in S:
\exists\delta(\varepsilon)>0
\text{ satisfying the uniform stability condition}
\right}.
]

The quantifier structure is fundamental:

[
\forall\varepsilon>0
\quad
\exists\delta>0
\quad
\forall x\in\mathcal{R}_{unif}
\quad
\forall y
\quad
\forall n\geq0.
]

---

## 54. Region of Asymptotic Stability

Let (A\subseteq S) be invariant.

A region (\mathcal{R}_{asym}) is asymptotically stable with respect to (A) when:

1. (A) is stable;
2. every trajectory starting in (\mathcal{R}_{asym}) remains controlled according to the stability criterion; and
3. trajectories approach (A).

Thus,

[
x\in\mathcal{R}_{asym}
\Longrightarrow
\operatorname{dist}(T^n(x),A)\rightarrow0.
]

---

## 55. Region of Exponential Stability

A region is exponentially stable with respect to (A) if there exist constants

[
C>0,
\qquad
0<\lambda<1
]

such that

[
d(T^n(x),A)
\leq
C\lambda^n d(x,A)
]

for all

[
x\in\mathcal{R}
]

and

[
n\geq0.
]

---

## 56. Region of Contractive Stability

A region is contractively stable if there exists

[
0\leq q<1
]

such that

[
d(T(x),T(y))
\leq
q,d(x,y)
]

for all admissible

[
x,y\in\mathcal{R}.
]

Repeated application gives

[
d(T^n(x),T^n(y))
\leq
q^n d(x,y).
]

---

## 57. Contractive Region

A contractive region is therefore a stability region with a one-step contraction bound.

Contractivity implies a particularly strong form of perturbation control.

The converse does not generally hold.

---

## 58. Region Stability and Fixed Points

If

[
T(x^\ast)=x^\ast,
]

then (x^\ast) is a fixed point.

A region (\mathcal{R}) around (x^\ast) may be stable if trajectories starting in (\mathcal{R}) remain near (x^\ast).

If additionally

[
T^n(x)\rightarrow x^\ast,
]

then the region provides asymptotic stability of the fixed point.

---

## 59. Region Stability and Periodic Orbits

Let

[
\mathcal{P}
===========

{x_0,T(x_0),\ldots,T^{p-1}(x_0)}
]

be a periodic orbit with period (p).

A stability region around (\mathcal{P}) is a set of states whose trajectories satisfy the selected stability criterion relative to the periodic orbit.

The distance is defined by

[
d(x,\mathcal{P})
================

\inf_{p\in\mathcal{P}}d(x,p).
]

---

## 60. Region Stability and Invariant Sets

Let

[
I\subseteq S
]

be invariant.

A stability region relative to (I) may be defined by

[
\mathcal{R}_I
=============

{x\in S:
\text{the trajectory of }x
\text{ remains sufficiently close to }I
}.
]

The invariant-set structure is inherited from SRM-0009.

---

## 61. Region Stability and Attractors

Let

[
A
]

be an attractor.

The stability region of (A) describes states whose transition behavior remains controlled while approaching (A).

Thus attraction and stability are related but distinct:

[
\operatorname{Attracts}(x,A)
\not\equiv
\operatorname{Stable}(x).
]

Both properties may coexist.

---

## 62. Stability Region Decomposition

Let

[
\mathcal{R}
===========

\bigcup_{i\in I}\mathcal{R}_i.
]

Each (\mathcal{R}_i) may represent a distinct stability mode.

For example,

[
\mathcal{R}
===========

\mathcal{R}*{fixed}
\cup
\mathcal{R}*{periodic}
\cup
\mathcal{R}_{attracting}.
]

Such a decomposition must preserve the definitions of the individual regions.

---

## 63. Stability Region Partition

A family

[
{\mathcal{R}*i}*{i\in I}
]

is a partition of (\mathcal{R}) if

[
\mathcal{R}
===========

\bigcup_{i\in I}\mathcal{R}_i
]

and

[
\mathcal{R}_i\cap\mathcal{R}_j=\varnothing
]

for

[
i\neq j.
]

Partitioning enables regional classification of transition behavior.

---

## 64. Stability Region Classification

A state may be classified according to membership in one or more regions:

[
x\mapsto
{\mathcal{R}_i:x\in\mathcal{R}_i}.
]

This produces a stability signature for the state.

---

## 65. Stability Signature

Define the stability signature

[
\Sigma(x)
=========

(\sigma_1(x),\ldots,\sigma_k(x))
]

where

[
\sigma_i(x)\in{0,1}
]

indicates whether (x) satisfies stability criterion (i).

Thus,

[
\sigma_i(x)=1
]

if and only if

[
x\in\mathcal{R}_i.
]

---

## 66. Regional Stability Map

Define

[
\Sigma:S\rightarrow{0,1}^k.
]

The map

[
\Sigma
]

assigns each state its stability classification.

This provides a formal mathematical representation of multi-criterion stability.

---

## 67. Stability Region Equivalence

Two regions

[
\mathcal{R}_1,\mathcal{R}_2
]

are stability-equivalent under a criterion (C) if

[
\forall x\in S,
\quad
x\in\mathcal{R}_1
\Longleftrightarrow
x\in\mathcal{R}_2
]

with respect to (C).

---

## 68. Region Refinement Relation

Define

[
\mathcal{R}_1\preceq\mathcal{R}_2
]

if

[
\mathcal{R}_1\subseteq\mathcal{R}_2.
]

The relation (\preceq) is a partial order on subsets of (S).

Therefore stability regions may be organized as a partially ordered family.

---

## 69. Stability Region Lattice

Under ordinary set inclusion, subsets of (S) form a complete lattice.

For stability regions closed under the required operations, meet and join are given by

[
\mathcal{R}_1\wedge\mathcal{R}_2
================================

\mathcal{R}_1\cap\mathcal{R}_2
]

and

[
\mathcal{R}_1\vee\mathcal{R}_2
==============================

\mathcal{R}_1\cup\mathcal{R}_2.
]

The admissible stability-region family need not itself form a complete lattice unless closure is proved.

---

## 70. Transition-Induced Region Operator

Define the image operator

[
\mathcal{T}(\mathcal{R})
========================

# T(\mathcal{R})

{T(x):x\in\mathcal{R}}.
]

Forward invariance becomes

[
\mathcal{T}(\mathcal{R})\subseteq\mathcal{R}.
]

Exact invariance becomes

[
\mathcal{T}(\mathcal{R})=\mathcal{R}.
]

---

## 71. Iterated Region Operator

Define

[
\mathcal{T}^0(\mathcal{R})=\mathcal{R}
]

and

[
\mathcal{T}^{n+1}(\mathcal{R})
==============================

\mathcal{T}(\mathcal{T}^n(\mathcal{R})).
]

Then

[
\mathcal{T}^n(\mathcal{R})
==========================

T^n(\mathcal{R}).
]

---

## 72. Forward Reachability of a Region

The forward reachable set of (\mathcal{R}) is

[
\operatorname{Reach}^{+}(\mathcal{R})
=====================================

\bigcup_{n=0}^{\infty}T^n(\mathcal{R}).
]

If

[
\mathcal{R}
]

is forward invariant, then

[
\operatorname{Reach}^{+}(\mathcal{R})
\subseteq
\mathcal{R}.
]

---

## 73. Stability Reachability

A stability region is transition-reachable internally if

[
T^n(x)\in\mathcal{R}
]

for every

[
x\in\mathcal{R}
]

and

[
n\geq0.
]

This is equivalent to positive invariance.

---

## 74. Region Escape

For

[
x\in\mathcal{R},
]

define the escape time

[
\tau_{\mathcal{R}}(x)
=====================

\inf
{n\geq0:T^n(x)\notin\mathcal{R}}.
]

If no such (n) exists, define

[
\tau_{\mathcal{R}}(x)=\infty.
]

---

## 75. Infinite Residence

A state has infinite residence in (\mathcal{R}) if

[
\tau_{\mathcal{R}}(x)=\infty.
]

A forward-invariant region therefore satisfies

[
\forall x\in\mathcal{R},
\quad
\tau_{\mathcal{R}}(x)=\infty.
]

---

## 76. Finite Residence Stability

A region may be stable over a finite horizon even if it is not invariant indefinitely.

For horizon (N),

[
\tau_{\mathcal{R}}(x)>N
]

means the trajectory remains in (\mathcal{R}) for the first (N) transitions.

---

## 77. Region Viability

Let

[
C\subseteq S
]

be a constraint region.

A state is viable in (C) if there exists an admissible transition sequence remaining within (C).

For deterministic (T), viability under the fixed transition operator requires

[
T^n(x)\in C
]

for the required horizon.

---

## 78. Viability Kernel

Define the infinite-horizon viability kernel

[
\operatorname{Viab}(C)
======================

{x\in C:
T^n(x)\in C
\text{ for all }n\geq0}.
]

For deterministic dynamics,

[
\operatorname{Viab}(C)
]

is the maximal forward-invariant subset of (C).

---

## 79. Stable Viability Kernel

If (C) represents an admissible stability constraint, define

[
\operatorname{SVK}(C)
=====================

\operatorname{Viab}(C)
\cap
\operatorname{Stab}(T).
]

This provides a region satisfying both viability and stability.

---

## 80. Certified Stability Region

A certified stability region is a region for which the selected stability claims have been mathematically justified according to the SMOF certification rules.

Denote it by

[
\mathcal{R}_{cert}.
]

Certification requires explicit:

1. hypotheses;
2. definitions;
3. transition assumptions;
4. stability criterion;
5. region construction;
6. proof or valid reduction;
7. boundary conditions;
8. perturbation conditions; and
9. conclusion.

---

## 81. Soundness of Certification

A certification procedure is sound if

[
\operatorname{Certify}(\mathcal{R})
\Longrightarrow
\operatorname{Stable}(\mathcal{R})
]

under the stated assumptions.

No computational approximation may be interpreted as a mathematical proof unless the approximation procedure itself provides the required certified bound.

---

## 82. Conservative Stability Region

A region

[
\mathcal{R}_{cons}
]

is conservative if

[
\mathcal{R}*{cons}
\subseteq
\mathcal{R}*{true}
]

where (\mathcal{R}_{true}) denotes the mathematically valid stability region.

Conservative regions are acceptable when their construction is sound.

---

## 83. Approximate Stability Region

A computational approximation

[
\widehat{\mathcal{R}}
]

may be used to estimate a stability region.

Approximation must be distinguished from certification:

[
\widehat{\mathcal{R}}
\neq
\mathcal{R}_{cert}
]

unless equivalence or a valid enclosure has been established.

---

## 84. Inner Approximation

An inner approximation satisfies

[
\widehat{\mathcal{R}}*{in}
\subseteq
\mathcal{R}*{true}.
]

If every point of the inner approximation is independently certified, then it may provide a conservative certified region.

---

## 85. Outer Approximation

An outer approximation satisfies

[
\mathcal{R}*{true}
\subseteq
\widehat{\mathcal{R}}*{out}.
]

An outer approximation cannot by itself certify that every included state is stable.

---

## 86. Region Error

For approximate regions, define the symmetric difference

[
\mathcal{R}_1\triangle\mathcal{R}_2
===================================

(\mathcal{R}_1\setminus\mathcal{R}_2)
\cup
(\mathcal{R}_2\setminus\mathcal{R}_1).
]

This provides a set-theoretic measure of disagreement between two region representations.

---

## 87. Metric Region Error

When a measure (\mu) is available, define

[
E(\mathcal{R}_1,\mathcal{R}_2)
==============================

\mu(\mathcal{R}_1\triangle\mathcal{R}_2).
]

This quantity may be used for convergence analysis of computational approximations.

---

## 88. Numerical Stability Region

A numerical stability region is a region inferred from numerical computation under a finite discretization or simulation scheme.

It must be represented as

[
\mathcal{R}_{num}(N,h,\epsilon)
]

where the arguments may represent:

* transition horizon (N);
* discretization scale (h);
* numerical tolerance (\epsilon).

Numerical stability is not automatically mathematical stability.

---

## 89. Convergence of Numerical Regions

A numerical sequence

[
\mathcal{R}_1,
\mathcal{R}_2,\ldots
]

may approximate a mathematical stability region if an appropriate convergence notion is specified.

Possible notions include:

[
d_H(\mathcal{R}_n,\mathcal{R})\rightarrow0
]

for Hausdorff distance, or measure convergence.

---

## 90. Stability Region Under Composition

Let

[
T_1:S\rightarrow S
]

and

[
T_2:S\rightarrow S.
]

The composed transition is

[
T=T_2\circ T_1.
]

A region stable under both operators may provide a stability region for the composition when

[
T_1(\mathcal{R})\subseteq\mathcal{R}
]

and

[
T_2(\mathcal{R})\subseteq\mathcal{R}.
]

Then

[
(T_2\circ T_1)(\mathcal{R})
\subseteq
\mathcal{R}.
]

## 91. Stability Region Under Iteration

For

[
T^k
]

the (k)-step transition operator, define

[
\mathcal{R}^{(k)}
=================

{x\in S:
\operatorname{Stable}_{T^k}(x)}.
]

Relations between

[
\mathcal{R}^{(k)}
]

and

[
\mathcal{R}^{(1)}
]

must be derived from the specific stability criterion.

---

## 92. Region Stability Under Conjugacy

Let

[
h:S\rightarrow S'
]

be a bijection and

[
T'=h\circ T\circ h^{-1}.
]

If the stability structure is preserved by (h), then a stability region

[
\mathcal{R}\subseteq S
]

maps to

[
\mathcal{R}'
============

h(\mathcal{R})\subseteq S'.
]

The conjugate system satisfies corresponding stability properties under compatible structural assumptions.

## 93. Region Invariants

A region property (P(\mathcal{R})) is transition invariant if

[
P(T(\mathcal{R}))=P(\mathcal{R})
]

whenever the relevant expressions are defined.

Examples may include:

* exact invariance;
* dimension;
* connectedness under homeomorphism;
* topological type; and
* specified algebraic structure.

---

## 94. Stability Region Observable

A stability-region observable is a function

[
O:\mathcal{P}(S)\rightarrow\mathbb{R}
]

or another admissible codomain that quantifies a region property.

Examples include:

[
O(\mathcal{R})=\mu(\mathcal{R}),
]

[
O(\mathcal{R})=M_{\min}(\mathcal{R}),
]

or

[
O(\mathcal{R})=\operatorname{diam}(\mathcal{R}).
]

---

## 95. Region Diameter

For a metric space,

[
\operatorname{diam}(\mathcal{R})
================================

\sup_{x,y\in\mathcal{R}}d(x,y).
]

Finite diameter provides a boundedness property.

Boundedness alone does not imply stability.

---

## 96. Stability Region Boundedness

A stability region is bounded if there exists

[
M>0
]

such that

[
d(x,x_0)\leq M
]

for all

[
x\in\mathcal{R}
]

and some reference point (x_0).

Boundedness must not be confused with invariance.

---

## 97. Stability Region Compactness

A region is compact when it satisfies the appropriate compactness criterion of the underlying topology.

In a finite-dimensional Euclidean space, a closed and bounded region is compact.

Compactness may simplify existence arguments for extrema and minimum stability margins.

---

## 98. Extremal Stability Margin

If (\mathcal{R}) is compact and (M_{\mathcal{R}}) is continuous, then

[
M_{\min}
========

\min_{x\in\mathcal{R}}M_{\mathcal{R}}(x)
]

exists.

Similarly,

[
M_{\max}
========

\max_{x\in\mathcal{R}}M_{\mathcal{R}}(x)
]

exists.

---

## 99. Stability Region Radius

For a center (x^\ast), define the largest certified radius

[

==============

\sup
{r>0:
B_r(x^\ast)
\subseteq
\operatorname{Stab}(T)}.
]

This is the maximal local stability radius under the chosen metric.

---

## 100. Regional Stability Radius

For a region (\mathcal{R}), define

[
r^\ast(\mathcal{R})
===================

\sup
{r>0:
\mathcal{R}_r
\text{ satisfies the required stability criterion}
}.
]

The exact definition of (\mathcal{R}_r) depends on the region construction.

---

## 101. Stability Region Expansion

[

\subseteq
\mathcal{R}_1
\subseteq

]

If every (\mathcal{R}_n) is certified stable, the union

[
\mathcal{R}_{\infty}
====================

\bigcup_{n=0}^{\infty}\mathcal{R}_n
]

may provide an expanded stability domain, subject to preservation of the required uniform properties.

## 102. Stability Region Contraction

[
\mathcal{R}_0
\supseteq
\mathcal{R}_1
\supseteq

]

is a stability-region contraction sequence.

The limiting region is

[
\mathcal{R}_{\infty}

\bigcap_{n=0}^{\infty}\mathcal{R}_n.
]

This construction is useful for progressively strengthening stability constraints.

## 103. Region Fixed Point

A region operator

[
F:\mathcal{P}(S)\rightarrow\mathcal{P}(S)
]

has a fixed region when

[
F(\mathcal{R})=\mathcal{R}.
]

For example, a stability-region construction may seek

[
\mathcal{R}
===========

F(\mathcal{R})
]

as the maximal region satisfying a recursive stability condition.

## 104. Region Preimage

This is the one-step predecessor region of (\mathcal{R}).

{x\in S:T^n(x)\in\mathcal{R}}.
]

Repeated preimages identify states that enter the target region after a specified number of transitions.

## 106. Basin Construction by Preimages

For an invariant attractor (A), a basin may be approximated through repeated preimages:

[
\mathcal{B}_0=A,
]

[
\mathcal{B}_{n+1}
=================

\mathcal{B}_n
\cup

]

Then

[
\mathcal{B}_\infty
==================

\bigcup_{n=0}^{\infty}\mathcal{B}_n

collects states that eventually enter the constructed target set.

## 107. Stability Core

Define the stability core of a region (C) as the maximal subset of (C) satisfying the required stability and invariance conditions.

Denote it by

[
\operatorname{Core}_{stab}(C).
]

Then

[
\operatorname{Core}_{stab}(C)
\subseteq C.
]

## 108. Maximal Stable Invariant Subset

Define

[
\operatorname{MSI}(C)
]

as the maximal subset

[
\mathcal{R}\subseteq C
]

such that

[
T(\mathcal{R})\subseteq\mathcal{R}
]

and

[
\operatorname{Stable}_T(x)
]

for every

[
x\in\mathcal{R}.
]

## 109. Stability Region Existence

A stability region exists under a criterion (C) if

[
\exists\mathcal{R}\subseteq S
]

such that

[
\forall x\in\mathcal{R},
\quad
C(x).
]

The empty set satisfies many purely universal formulations but must not automatically be accepted as a meaningful stability region.

A nonempty condition is therefore required when the specification intends a physically or mathematically populated region:

[
\mathcal{R}\neq\varnothing.
]

---

## 110. Nonempty Certified Region

A certified stability claim requires

[
\mathcal{R}_{cert}\neq\varnothing.
]

The certification record must identify at least one state, family, neighborhood, or constructive representation establishing nonemptiness.

---

## 111. Region Consistency

A stability region is internally consistent if all stated region constraints can be simultaneously satisfied.

For constraints

[
C_1,\ldots,C_k,
]

consistency requires

[
\exists x\in S
]

such that

[
\bigwedge_{i=1}^{k}C_i(x).
]

Equivalently,

[
\bigcap_{i=1}^{k}\mathcal{R}_i
\neq
\varnothing.
]

---

## 112. Region Conflict

A set of constraints is conflicting if

[
\bigcap_{i=1}^{k}\mathcal{R}_i
==============================

\varnothing.
]

A certification process must distinguish:

* stable;
* unstable;
* unverified; and
* inconsistent.

These are not interchangeable outcomes.

---

## 113. Region Unknown State

For computational analysis, define a classification function

[
C:S\rightarrow
{
Stable,
Unstable,
Unknown
}.
]

The unknown class represents insufficient evidence.

It must not be interpreted as instability.

---

## 114. Certified Classification

A state may be classified as certified stable only when

[
C(x)=Stable
]

is supported by a valid proof, bound, or certified reduction.

Numerical observation alone does not establish certification.

[
C_{\mathcal{R}}(x)

\end{cases}

This characteristic function provides the simplest mathematical representation of region membership.

\begin{cases}

It may be used by algorithms for classification, sampling, and verification.

\widehat{p}_{stable}

\frac{1}{N}

## 119. Stability Region Probability

]

This describes the probability that a randomly distributed initial state lies inside the stability region.

It does not replace deterministic stability analysis.

## 122. Stability Kernel Approximation

## 123. Stability Region Algorithm

A generic stability-region analysis consists of:

1. define (S);
2. define (T);
3. define the stability criterion;
4. define admissible perturbations;
5. construct an initial candidate region;
6. test transition preservation;
7. test stability;
8. test boundary conditions;
9. refine the region;
10. repeat until the required criterion is satisfied;
11. record assumptions;
12. certify the resulting region.

## 124. Mathematical Region Construction

The canonical construction is

[
\mathcal{R}_0=S
]

followed by iterative restriction:

[
\mathcal{R}_{k+1}
=================

\mathcal{R}_k
\cap
C_k
\cap
T^{-1}(\mathcal{R}_k)
]

where (C_k) is the stability constraint at iteration (k).

The sequence is decreasing:

[
\mathcal{R}_{k+1}\subseteq\mathcal{R}_k.
]

---

## 125. Limit Region

Define

[
\mathcal{R}^{\ast}
==================

\bigcap_{k=0}^{\infty}\mathcal{R}_k.
]

Under suitable conditions,

[
T(\mathcal{R}^{\ast})
\subseteq
\mathcal{R}^{\ast}.
]

Additional assumptions are required to establish the complete stability property.

## 126. Region Construction Theorem

**Theorem.**
Let

[
\mathcal{R}_0\supseteq\mathcal{R}_1\supseteq\cdots
]

be a decreasing sequence of subsets of (S) satisfying

[
T(\mathcal{R}_k)\subseteq\mathcal{R}_k
]

for every (k).

If

[
\mathcal{R}^{\ast}
==================

\bigcap_{k=0}^{\infty}\mathcal{R}_k,
]

then

[
T(\mathcal{R}^{\ast})
\subseteq
\mathcal{R}^{\ast}.
]

**Proof.**

Let

[
x\in\mathcal{R}^{\ast}.
]

Then

[
x\in\mathcal{R}_k
]

for every (k).

Since

[
T(\mathcal{R}_k)\subseteq\mathcal{R}_k,
]

we obtain

[
T(x)\in\mathcal{R}_k
]

for every (k).

Therefore,

[
T(x)\in
\bigcap_{k=0}^{\infty}\mathcal{R}_k
===================================

\mathcal{R}^{\ast}.
]

Hence

[
T(\mathcal{R}^{\ast})
\subseteq
\mathcal{R}^{\ast}.
]

[
\boxed{\square}
]

## 127. Stability Region Restriction Theorem

Let

[
\mathcal{R}
]

be a stability region and let

[
C\subseteq S.
]

If

[
\mathcal{R}'=\mathcal{R}\cap C,
]

then

[
\mathcal{R}'\subseteq\mathcal{R}.
]

Therefore every pointwise stability property inherited under restriction remains valid on (\mathcal{R}').

---

## 128. Proof

Let

[
x\in\mathcal{R}'.
]

Then

[
x\in\mathcal{R}
]

by definition of intersection.

Since (\mathcal{R}) is stable,

[
\operatorname{Stable}_T(x).
]

Therefore (\mathcal{R}') is pointwise stable.

[
\boxed{\square}
]

## 129. Forward-Invariance Theorem

Let

[
T:S\rightarrow S
]

and

[
\mathcal{R}\subseteq S.
]

If

[
T(\mathcal{R})\subseteq\mathcal{R},
]

then

[
T^n(\mathcal{R})\subseteq\mathcal{R}
]

for every

[
n\geq0.
]

This is the fundamental region-preservation theorem.

---

## 130. Proof

For

[
n=0,
]

we have

[
T^0(\mathcal{R})=\mathcal{R}.
]

Assume

[
T^n(\mathcal{R})\subseteq\mathcal{R}.
]

Then

[
T^{n+1}(\mathcal{R})
====================

T(T^n(\mathcal{R}))
\subseteq
T(\mathcal{R})
\subseteq
\mathcal{R}.
]

Therefore the property holds by induction.

[
\boxed{\square}
]

---

## 131. Stability Region Composition Theorem

Suppose

[
T_1(\mathcal{R})\subseteq\mathcal{R}
]

and

[
T_2(\mathcal{R})\subseteq\mathcal{R}.
]

Then

[
(T_2\circ T_1)(\mathcal{R})
\subseteq
\mathcal{R}.
]

Thus a region invariant under each component transition is invariant under their composition.

---

## 132. Proof

We have

[
T_1(\mathcal{R})\subseteq\mathcal{R}.
]

Applying (T_2),

[
T_2(T_1(\mathcal{R}))
\subseteq
T_2(\mathcal{R})
\subseteq
\mathcal{R}.
]

Hence

[
(T_2\circ T_1)(\mathcal{R})
\subseteq
\mathcal{R}.
]

[
\boxed{\square}
]

## 133. Stability Region and Orbit Closure

For

[
